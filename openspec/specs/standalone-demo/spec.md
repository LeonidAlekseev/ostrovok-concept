# standalone-demo Specification

## Purpose
Демо-версия без базы (ветка `standalone`): сайт на снимке живой базы, вшитом в сборку, записи пользователя в браузере, вход в демо-кабинеты без паролей.

## Requirements

### Requirement: Демо-версия без базы
Ветка `standalone` SHALL собираться и работать без Supabase: данные SHALL читаться из снимка `data/standalone` и карт `public/standalone/maps`, переменные `NEXT_PUBLIC_SUPABASE_*` и `SUPABASE_*` SHALL не требоваться.

#### Scenario: Сборка без переменных Supabase
- **WHEN** `npm run build` запускают с пустыми переменными Supabase
- **THEN** сборка проходит, а страницы отелей, поиск и API отвечают данными снимка

### Requirement: Цифры как в полной версии
Ответы PostGIS-функций для точек отелей SHALL браться из записанных при экспорте по имени и аргументам; вид, шум и цены SHALL совпадать с полной версией.

#### Scenario: Вид из отеля
- **WHEN** открывают `/api/hotels/{id}/view` настоящего отеля
- **THEN** ответ совпадает с ответом полной версии на той же базе

### Requirement: Записи в браузере
Чаты Эвала, сообщения и ответы отельера, знания из ответов отельера, брони и ссылки «Поделиться» SHALL храниться в `localStorage`. Запросы к API SHALL нести эти строки, а маршрут SHALL возвращать свои записи после тела ответа.

#### Scenario: Ответ отельера в поиске
- **WHEN** отельер отвечает гостю с разрешением использовать ответ, а гость в том же браузере спрашивает Эвала
- **THEN** Эвал и поиск по фрагментам находят ответ отельера

#### Scenario: Переписка в одном браузере
- **WHEN** гость пишет отельеру, затем входит демо-отельером и отвечает, затем снова входит гостем
- **THEN** гость видит ответ отельера

### Requirement: Вход в демо без паролей
Демо-кабинеты SHALL открываться кнопками «Войти в демо-аккаунт» и «Демо отельер» через cookie `standalone-demo` без паролей и ключей; вход по почте SHALL сообщать, что недоступен в демо-версии.

#### Scenario: Демо-путешественник
- **WHEN** гость нажимает «Войти в демо-аккаунт»
- **THEN** в «Моих чатах» видны готовые демо-чаты снимка
