# semantic-search Specification

## Purpose
Поиск объектов каталога по смыслу текста: векторы `nemotron-3.5-embed-8b` в Supabase pgvector, реранжирование `nemotron-3.5-rerank-8b`; при недоступности моделей — прежние правила.

## Requirements

### Requirement: Векторы каталога
Отели каталога SHALL иметь векторы `nemotron-3.5-embed-8b` в Supabase pgvector. Скрипт загрузки SHALL пересчитывать только изменённые отели и SHALL не создавать документов маршрутов; запись — только сервисным ключом. Поиск по смыслу SHALL искать только отели.

#### Scenario: Повторный запуск
- **WHEN** `db:embed` запускается второй раз без изменений каталога
- **THEN** новых запросов к модели нет

#### Scenario: Только отели
- **WHEN** выполняется `db:embed`
- **THEN** загружаются документы только вида `hotel`

### Requirement: Поиск по смыслу
Сервер SHALL находить объекты по тексту: ближайшие векторы, затем реранжирование `nemotron-3.5-rerank-8b`. При ошибке или недоступности модели SHALL возвращаться прежний подбор по правилам без сообщения об ошибке.

#### Scenario: Смысловой запрос
- **WHEN** помощнику пишут «тихий хостел с быстрым Wi‑Fi в Праге»
- **THEN** первые варианты — хостелы Праги с Wi‑Fi не ниже 100 Мбит/с

#### Scenario: Модель недоступна
- **WHEN** модель эмбеддингов не ответила
- **THEN** помощник отвечает по прежним правилам
