# Proposal

## Why

Шаблон «Результаты поиска — список, фильтры, сортировка, карта» (запрос пользователя 2026-10-19). Сейчас результаты показываются под формой на главной и содержат только направления, без отелей. Решения пользователя: поиск с главной ведёт на `/search`; карта — MapLibre + OSM.

## What Changes

- Страница `/search`: сводка запроса с возможностью изменить поиск, список отелей, фильтры, сортировка, карта.
- Фильтры: цена за ночь (диапазон), звёзды, рейтинг от, питание, бесплатная отмена. Сортировка: «Сначала популярные» (по умолчанию), «Сначала дешевле», «Сначала дороже», «По рейтингу». Фильтры и сортировка хранятся в адресе.
- Карта: `maplibre-gl` с тайлами OpenFreeMap (без ключа), маркеры с ценой, связь карточек и маркеров, ленивая загрузка только на `/search`. Без сети список работает, вместо карты — сообщение.
- Поиск с главной во всех режимах ведёт на `/search` с параметрами запроса; блок результатов под формой убирается.
- Карточка отеля в списке ведёт на `/hotels/<id>` с датами и гостями запроса.

## Capabilities

### New Capabilities

- `search-results-page`: страница результатов поиска.

### Modified Capabilities

- `manual-search`: поиск выполняется переходом на `/search`, результаты — на странице результатов.
- `assistant-search`: выбор варианта плана ведёт на `/search`.

## Impact

- Новые `src/app/search/*`, `src/components/SearchResultsPage/*` (имя — на усмотрение исполнителя).
- `src/hooks/useHotelSearch.ts`, `src/components/SearchForm/{SearchForm,SearchResults}.tsx`, `src/components/SearchPanel/AssistantSearch.tsx`, `src/lib/search.ts`.
- `package.json`, `package-lock.json`: `maplibre-gl`.
- Зависит от `add-prototype-foundation`.

## Замер JS

Методика как в `add-prototype-foundation`: `npm run build`; берутся все `<script src>` чанки из `.next/server/app/<страница>.html`; для каждого размер в байтах и `gzip -9 -c | wc -c`; значения суммируются. Код карты в HTML не входит: он подгружается динамическим импортом, его чанки сняты по сетевым запросам headless Chromium на `/search` после загрузки карты.

Прирост главной — `next/navigation` (`useRouter` в `useHotelSearch`) и общие с `/search` чанки формы поиска; блок результатов и демо-поиск с главной ушли. MapLibre на главной не загружается. На узких экранах чанк карты и воркер загружаются только после переключения на «Карта».
