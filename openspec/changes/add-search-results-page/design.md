# Design

## Context

Каталог, контракт параметров и кнопка избранного — из `add-prototype-foundation`. Next.js 16: `/search` пререндерится статически, параметры читаются на клиенте (`useSearchParams` внутри Suspense); перед кодом читать `node_modules/next/dist/docs/`.

## Goals / Non-Goals

**Goals:**
- Рабочий список, фильтры, сортировка и карта на демо-каталоге.
- Состояние страницы восстанавливается по адресу.

**Non-Goals:**
- Страница отеля (change `add-hotel-pages`), подборки на главной.
- Поиск по видимой области карты, кластеризация маркеров.

## Decisions

**Параметры адреса:** запрос — как у поиска (`destination` или `scenario`, `checkin`, `checkout`, `adults`, `children`, `rooms`); фильтры — `price_min`, `price_max`, `stars` (список через запятую), `rating` (6, 7, 8, 9), `meal` (список), `free_cancel=1`; сортировка — `sort` (`popular`, `price_asc`, `price_desc`, `rating`). Изменение фильтров заменяет адрес без новой записи истории.

**Поиск с главной:** `useHotelSearch` после валидации выполняет переход `router.push('/search?…')`. Демо-задержка ~700 мс переносится на страницу результатов (состояние загрузки «Ищем варианты…»). Невалидный или пустой запрос на `/search` показывает форму поиска с ошибками валидации.

**Карта:** `maplibre-gl`, стиль `https://tiles.openfreemap.org/styles/liberty`, атрибуция © OpenStreetMap и OpenFreeMap. Модуль карты грузится динамическим импортом на клиенте. Desktop (`lg` и шире): список и карта рядом; мобильные: переключатель «Список / Карта». Наведение или фокус на карточке подсвечивает маркер; нажатие на маркер подсвечивает и прокручивает к карточке. Ошибка загрузки стиля или тайлов — «Карта недоступна», список работает. В jsdom модуль карты подменяется моком.

**Карточка отеля:** заглушка фото, название, звёзды, рейтинг и число отзывов, расстояние до центра, бейджи «Бесплатная отмена» и питание минимального тарифа, цена «от N ₽ за M ночей», кнопка избранного, ссылка на отель.

**Пустой результат:** «Ничего не нашлось» и кнопка «Сбросить фильтры».

## Risks / Trade-offs

- [Размер `maplibre-gl` ~200 КБ gzip] → Только на `/search`, динамический импорт; замер JS главной и `/search` записать в proposal.md.
- [Внешний сервис тайлов] → Без ключа и данных пользователя; при недоступности — сообщение.
- [Меняется поведение поиска на главной] → Delta-спецификации `manual-search` и `assistant-search`, тесты обновляются.
