## MODIFIED Requirements

### Requirement: Блок на главной
Главная SHALL показывать секцию `#stars` на изображении ночного неба: сверху изображение магического шара в зодиакальном круге с орбитой, по центру золотой заголовок «Звёзды подскажут», описание и кнопку «Найти по звёздам», открывающую модальное окно «Звёзды подскажут». Зодиакальный круг SHALL медленно вращаться; при `prefers-reduced-motion: reduce` SHALL быть неподвижным.

#### Scenario: Открытие окна
- **WHEN** пользователь нажимает «Найти по звёздам»
- **THEN** открывается модальное окно «Звёзды подскажут» с анкетой, фокус в первом поле

#### Scenario: Меньше движения
- **WHEN** у пользователя включено `prefers-reduced-motion: reduce`
- **THEN** зодиакальный круг неподвижен
