## Why

Исполнитель `chat-list-mobile-flat` (#278) измерил: на 1440 px в `dev` сетка страницы Эвала растягивается по содержимому (9 539 px при окне 800 px) — лента не прокручивается внутри, поле ввода уходит за экран. Причина: `flex-1` контейнера сетки внутри `main` без определённой высоты (`src/components/AssistantPage/AssistantPage.tsx:21`, `AssistantSearch.tsx:181`). Это нарушает требование «Чат для долгих диалогов» — регрессия, исправляется без нового поведения.

## What Changes

- От `lg` страница Эвала занимает ровно высоту экрана; колонки (список, чат, правая) прокручиваются внутри себя; поле ввода чата закреплено внизу.
- На телефоне поведение после #278 не меняется.

## Impact

- Спецификация `assistant-search`, требование «Чат для долгих диалогов» — добавлен сценарий для компьютера.
- Код: `src/components/AssistantPage/AssistantPage.tsx`, `AssistantSearch.tsx` (классы высоты), тест раскладки.
