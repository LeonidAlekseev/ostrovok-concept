## Решения

- **Один источник.** Всё чтение каталога идёт через один модуль доступа (синхронный сейчас). Остальные модули — чистые функции от входных данных. В `catalog-from-supabase` модуль доступа станет серверным (`src/lib/db/catalog.ts`), а клиент получит данные пропсами или через `GET /api/hotels?ids=`.
- **Что передавать на клиент.** Клиентским компонентам — только нужное: `HotelSummary` для списков и карт, полный `Hotel` — для страницы отеля. Не тянуть весь каталог в клиентский бандл ради одной страницы.
- **Без новых зависимостей и без изменения поведения.** Проверка — тот же набор тестов и снимки ключевых страниц без визуальных отличий.
