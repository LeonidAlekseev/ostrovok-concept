## ADDED Requirements

### Requirement: Один ответ на сообщение
На каждое сообщение пользователя Эвал SHALL давать ровно один ответ: повторный запуск хода для уже отвеченного сообщения SHALL не создавать второго ответа. Ожидающий ответ после перезагрузки SHALL запрашиваться один раз.

#### Scenario: Быстрый повторный рендер
- **WHEN** ответ Эвала пришёл и список чатов перерисовался до сохранения ответа
- **THEN** в ленте один ответ на сообщение, второго запроса нет
