## Why
Пользователь прислал новый шар для гадания с альфа-каналом и макет окна «Поиск по звёздам» в космическом стиле, отдельно фон и кнопку. Видео результата должно быть таким же красивым в этом стиле.

Исходники (вне репозитория, не коммитить как есть): `/home/agent/star-assets/`
- `orb.png` — шар 1254×1254 RGBA;
- `modal-mockup.jpeg` — макет окна (1006×1564);
- `modal-bg.jpeg` — фон окна: космос, фиолетовые облака, золотые линии (1006×1564);
- `button.jpeg` — фон кнопки «Гадать» на чёрном (2000×667, без альфы: чёрный убрать в прозрачность).

## What Changes
- Шар: `public/images/stars/orb.webp` из `orb.png` (640×640, сфера по центру, прозрачный фон); используется везде, где сейчас (блок, анимация, результат, видео).
- Окно «Поиск по звёздам» по макету: фон-картинка, тонкая золотая рамка, заголовок золотым антиква-шрифтом в две строки, шар справа сверху, подписи полей с золотыми иконками (имя, дата рождения, когда едем, куда/с кем), поля — тёмное стекло с фиолетовой обводкой, кнопка «Гадать» на фоне `button` с иконкой звезды и стрелкой. Поля и логика анкеты не меняются, только вид (поля из макета, которых нет в анкете, не добавлять).
- Результат гадания и видео 1080×1920 в том же стиле: тот же фон, золотые акценты, новый шар, золотая типографика заголовков.
