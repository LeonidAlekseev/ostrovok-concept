# Design

- **Источник дат.** `HotelStay` сейчас читает даты из адреса через `useStay` и пишет их обратно `router.replace`. Для окна нужен вариант без адреса: `useStay` (или `HotelStay`) принимает начальный `stay` и режим «локально» — состояние в `useState`, без `router.replace`. Страницы отеля и тарифов работают как сейчас.
- **Начальные даты окна.** `stay` из `SearchResultsPage` — тот же, по которому считается список (включая стартовые даты при пустом адресе).
- **Сброс.** Открытие окна другого отеля начинает с дат поиска, а не с дат, выбранных в прошлом окне.
- **Ссылки из окна.** «Открыть страницу отеля» и «Выбрать номер» внутри окна ведут с датами окна.
- **Сетка.** `grid gap-3 2xl:grid-cols-2`.
