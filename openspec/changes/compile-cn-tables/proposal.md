# Proposal

## Why

Оценка `evaluate-server-components` (архив) показала: пакет `cn` занимает ≈ 25,7 КБ сырых в чанке главной — больше, чем `Hero`. Это полный набор таблиц слияния классов Tailwind. У пакета есть штатный режим `cn build`: таблицы компилируются под классы, которые реально встречаются в проекте, а функция `cn` и результат слияния остаются прежними.

## What Changes

- Подключить `withCn` из `cn/next` в `next.config.ts`: таблицы строятся при `next build` и обновляются в `next dev`.
- `src/lib/utils.ts` экспортирует `cn`, собранный через `createCn` из `cn/engine` и сгенерированных таблиц.
- Примитивы `src/components/ui/*` импортируют `cn` из `@/lib/utils`, а не из пакета, чтобы в бандл попадали только скомпилированные таблицы.
- Генерация таблиц для `typecheck`, `lint` и `test` без `next build`: отдельный npm-скрипт.
- Решение о внедрении принимается по замеру: если выигрыш JS главной меньше 2 КБ gzip, изменения кода откатываются, а в change записывается замер и вывод.

Поведение не меняется, поэтому delta-спецификаций нет (`skip_specs: true`).

## Impact

- `next.config.ts`, `package.json`, `.gitignore`, `src/lib/utils.ts`, импорты в `src/components/ui/*.tsx`.
- Новый генерируемый модуль таблиц (не коммитится).
- CLI `cn` требует Node 22+, а в `engines` указано `>=20.9`. Нужно проверить версию Node в Vercel и при необходимости поднять `engines`.
