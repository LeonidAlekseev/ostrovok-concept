## Why

Находки исполнителей этапа 2026-10-25; пользователь принял их одним change (вопрос 31а, 2026-10-26) с двумя уточнениями: «Апартаменты» на узкой карточке сокращать до «Апарт…», длинные названия чатов обрезать в конце многоточием. Сюда же — названия быстрых ответов как у стартовых чипов (вопрос 28а).

## What Changes

- `Badge` `destructive`: контраст не ниже 4,5:1.
- `HotelTile`: на узкой карточке тип жилья сокращается («Апартаменты» → «Апарт…»), строка расстояния не ломается.
- Список чатов: длинное название обрезается многоточием в конце, время не вытесняет его.
- Быстрые ответы на вопрос о теме: «В город» вместо «Города Европы», «Куда угодно» вместо «Удиви меня» (разбор «удиви меня» сохраняется).
- Удалить неиспользуемые `glassPanel` и связанные константы (`src/components/SearchPanel/glass.ts`), мёртвые `--decor-assistant-*` (`src/app/globals.css`), мёртвые `max-sm:*` окна отеля (`HotelDialog.tsx:44`).
- README: цепочки моделей (текст, фото: super-vl → minimax), эмбеддинги `embed-1b`.
- AI SDK: часть `image` → `file` с `mediaType` (`src/lib/ai/vision.ts`).
- `weekday`: кешировать `Intl.DateTimeFormat` (`src/lib/dates.ts:31`).
- Разбить `SearchResultsPage.test.tsx` на несколько файлов; тест `:937` («opens the hotel page instead of the dialog… on narrow screens») — ожидание через `waitFor`.
- `.returns<>` → `overrideTypes` в `src/lib/db/catalog.ts` вместе с моком `catalog.test.ts`.

- Лента Эвала: отели всех планов чата — одним запросом/кешем, при сбое загрузки — повтор.
- Спека `search-modes`: выбор варианта Эвала ведёт на страницу отеля; `/search` — «Фильтры» и город без отеля.
