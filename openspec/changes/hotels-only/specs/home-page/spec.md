## MODIFIED Requirements

### Requirement: Состав и порядок секций
Страница SHALL рендерить по порядку: шапку, hero (`h1` «Путешествуй легко»), секцию поиска `#search` (aria-label «Поиск отелей») только с ассистентом, подборки отелей по персонам `#personas`, секцию поиска вайба `#vibe`, секцию поиска по звёздам `#stars` и баннер `#explore`. Документ SHALL иметь `lang="ru"`, title «О!Погнали — бронирование отелей» и `theme-color` `#a5e87b`.

#### Scenario: Якоря секций
- **WHEN** пользователь переходит по ссылке `#search`, `#personas`, `#vibe`, `#stars` или `#explore`
- **THEN** страница прокручивается к соответствующей секции

#### Scenario: Нет витрины маршрутов
- **WHEN** пользователь открывает главную
- **THEN** на ней нет секции `#routes` и ссылок на `/routes/<id>`

#### Scenario: Нет ручной формы на главной
- **WHEN** пользователь открывает главную
- **THEN** на ней нет вкладки «Вручную» и полей дат и гостей ручного поиска

#### Scenario: Статический пререндер
- **WHEN** выполняется `npm run build`
- **THEN** главная страница пререндерится статически без переменных окружения

#### Scenario: Слоган
- **WHEN** пользователь открывает главную
- **THEN** заголовок hero — «Путешествуй легко»

## ADDED Requirements

### Requirement: Подборки отелей по персонам
Секция `#personas` с заголовком «Подборки отелей для вас» SHALL показывать вкладки 4 персон (паттерн WAI-ARIA Tabs, подписи из `PERSONA_LABEL`) и до 6 отелей каталога выбранной персоны из разных городов общей карточкой отеля со ссылкой на `/hotels/<id>`. Персона без отелей SHALL не показываться. По умолчанию выбрана первая персона.

#### Scenario: Переход к отелю
- **WHEN** пользователь нажимает карточку отеля в подборке
- **THEN** открывается `/hotels/<id>` этого отеля

### Requirement: Отели персоны
Отели персоны SHALL подбираться правилами на сервере, по одному на город: «Студент» — самые дешёвые с оценкой гостей не ниже 7, «Люкс» — отели 5★ с лучшей оценкой, «Воркейшн» — с рабочей зоной и самым быстрым Wi‑Fi, «Культура» — ближе всего к центру с оценкой не ниже 8.

#### Scenario: Смена персоны
- **WHEN** пользователь выбирает вкладку «Воркейшн»
- **THEN** показываются отели с рабочей зоной из разных городов, первым — с самым быстрым Wi‑Fi
