# Design

## Context

`normalize` в `src/lib/search.ts` приватный. `suggestDestinations` уже ищет сценарий через `normalize`. `DestinationField` ищет его отдельно через `toLowerCase()`, чтобы добавить пункт сценария в список подсказок. См. proposal.md — Why.

## Goals / Non-Goals

**Goals:**
- Один источник правды для сравнения текста со сценарием.

**Non-Goals:**
- Изменение списка сценариев и их заголовков.
- Изменение логики подсказок направлений.

## Decisions

**Функция `findScenario(text)` в `lib/search.ts`.** Она использует `normalize` и возвращает сценарий или `undefined`. `DestinationField` вызывает её вместо собственного `find`. Альтернатива — экспортировать `normalize` — отвергнута: компоненты получили бы правило нормализации и могли бы снова разойтись.

## Risks / Trade-offs

- [Изменится выдача подсказок для текстов с «ё»] → Это и есть исправление; тест фиксирует новое поведение.
