# Proposal

## Why

Запрос пользователя 2026-10-20: вынести случайный выбор из панели поиска в отдельный блок главной. Блок с переливающимся магическим шаром и кнопкой «Найти по звёздам» открывает модальное окно «Поиск по звёздам»: гадание по знаку зодиака на реальных механизмах гороскопов, результат — отель, которым можно поделиться коротким вертикальным видео с логотипом «Островок!» и слоганом «Найди свой уголок».

## What Changes

- Вкладка «Случайность» и слот-машина удаляются из панели поиска; в панели остаются «Ассистент» и «Вручную».
- Секция `#stars` на главной: магический шар с переливом, заголовок, кнопка «Найти по звёздам».
- Модальное окно «Поиск по звёздам»: анкета → гадание (анимация шара) → результат.
- Астрологический расчёт в `src/lib/horoscope.ts` (вместо `src/lib/fortune.ts`): солнечный знак по дате рождения, стихия и модальность, транзит Солнца и Луны на дату заезда, фаза Луны, аспекты между знаками, астрологическая география городов каталога.
- Результат: прогноз, отель и 2 запасных варианта со ссылками на `/hotels/<id>` с датами поездки.
- Видео 1080×1920, около 8 секунд, рендер в браузере (canvas + `MediaRecorder`): «Поделиться видео» через Web Share API с файлом, иначе «Скачать видео» и копирование ссылки.
- Общий модуль медиа для отправки `src/lib/shareMedia.ts` (бренд-кадр, запись видео, отправка файла); его переиспользует `add-vibe-search`.

## Capabilities

### New Capabilities

- `star-search`: блок и модальное окно поиска по звёздам, расчёт, видео.

### Modified Capabilities

- `random-search`: удаляется целиком (заменяется `star-search`).
- `search-modes`: две вкладки.
- `home-page`: секция `#stars`.

## Impact

- Удаляются `src/components/SearchPanel/RandomSearch.tsx`, `src/lib/fortune.ts` и их тесты.
- `SearchPanel.tsx`, `HomePage.tsx`, новые `src/components/StarSearch/`, `src/lib/horoscope.ts`, `src/lib/shareMedia.ts`.
- `globals.css`: анимация перелива шара в `@theme` (`--animate-*`).
- Без новых зависимостей.
