# Design

- **Параметр.** `page` — отдельно от `FILTER_PARAMS`: `setFilterParams` удаляет `page`, поэтому любая смена фильтров возвращает к первой странице. `parsePage(params, pageCount)` — целое в `[1, pageCount]`.
- **Разбиение.** `items` после `applyFilters` → `items.slice((page − 1) × 12, page × 12)` для списка; карта получает все `items`.
- **Навигация.** `nav aria-label="Страницы результатов"`, ссылки `<Link href="?...page=N" scroll={false}>`, текущая — `aria-current="page"`. Больше 7 страниц — многоточия: первая, последняя, текущая ±1. При одной странице навигация не показывается.
- **Прокрутка.** После смены `page` — `scrollIntoView` к началу списка (с учётом reduced motion) и фокус на заголовок результатов (`tabIndex={-1}`).
- **Окно отеля.** `hotel=<id>` и `page` живут вместе; закрытие окна не сбрасывает страницу.
- **Подсветка.** Существующая связь «карточка → маркер» (`active`) не меняется; маркеры других страниц тоже на карте и подсвечиваются только при наведении на их карточку — когда она видна.
