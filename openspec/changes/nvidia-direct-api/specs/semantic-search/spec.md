## ADDED Requirements

### Requirement: Модели через API NVIDIA
Эмбеддинги, реранк и языковая модель помощника SHALL вызываться через API NVIDIA с ключом `NVIDIA_API_KEY` из секретов сервера. Без ключа или при ошибке SHALL работать прежний запасной путь без модели. Скрипты загрузки векторов SHALL соблюдать лимит 40 запросов в минуту.

#### Scenario: Ключ есть
- **WHEN** задан `NVIDIA_API_KEY` и пользователь пишет помощнику
- **THEN** запрос уходит в API NVIDIA, ответ — по смыслу

#### Scenario: Нет ключа
- **WHEN** `NVIDIA_API_KEY` не задан
- **THEN** помощник и вайб работают по правилам без сообщения об ошибке

#### Scenario: Лимит
- **WHEN** `db:embed` получает ответ 429
- **THEN** скрипт ждёт и повторяет запрос, не теряя отели
