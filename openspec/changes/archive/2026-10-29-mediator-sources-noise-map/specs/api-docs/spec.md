## ADDED Requirements

### Requirement: Пример карты шума — весь ответ

Пример ответа `GET /api/hotels/{hotelId}/noise-map` в документе OpenAPI SHALL быть полным ответом базы для отеля примера (все фигуры, включая «тишину»), а не его частью, чтобы карта «Пример на карте» рисовала круг шума целиком.

#### Scenario: Карта примера

- **WHEN** открыт пример «Шум вокруг отеля · ota-7481548»
- **THEN** на карте виден весь круг шума радиусом 300 м вокруг отеля
