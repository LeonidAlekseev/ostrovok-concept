## Why

Эвал не может ответить на вопросы о местах рядом с отелем: есть ли рядом больница, сколько идти до аптеки, есть ли бар или клуб, сколько до моря, до центра, до аэропорта. Сейчас `src/lib/ai/hotelAnswer.ts` на такие вопросы честно говорит «данных о местах рядом пока нет» (`NO_NEARBY_DATA`). Нужны данные OpenStreetMap и гео-инструменты. Решение пользователя: заранее загрузить нужные точки Валенсии в PostGIS, а то, чего в базе нет, запрашивать у OSM онлайн и дописывать в базу навсегда.

## What Changes

- Порт основы [NERVsystems/osmmcp](https://github.com/NERVsystems/osmmcp) (MIT) на TypeScript в `src/lib/geo/`, без MCP SDK, Go и дочерних процессов: геокодирование и обратное геокодирование (Nominatim, поиск ограничен Валенсией), места рядом по категориям (кэш PostGIS, иначе Overpass), расстояние по гаверсинусу, пешеходный маршрут (OSRM FOSSGIS `routed-foot`); если маршрут не получен вовремя, отдаётся расстояние по прямой с явной пометкой «по прямой».
- Инструменты описаны как `tool()` Vercel AI SDK с zod-схемами; результаты типизированы (точки, расстояния, GeoJSON маршрута) для будущей карты на MapLibre. Вызов инструментов в ходе Эвала и сообщение с картой — следующий change `assistant-map-message`, здесь не делаются.
- Честные ошибки: лимит сервиса — «сервис ограничил запросы, подождите N с», недоступность и таймаут — «не удалось проверить»; ничего не выдумывается.
- Лимиты частоты по правилам сервисов (Nominatim 1 запрос в секунду, Overpass и OSRM бережно), общие для всех инстансов через `rate_limit_hit`, без Supabase — в памяти. Свой User-Agent с адресом репозитория, таймауты под бюджет хода Эвала (9 с).
- Миграция `20261026130000_osm_places.sql`: таблицы `osm_places` (места) и `osm_place_areas` (какие области и категории уже загружены), RPC `osm_places_near` для чтения и `osm_place_area_add` для записи покрытия. Пишет только service role.
- Скрипт `npm run db:osm-places` загружает точки Валенсии (город, побережье, аэропорт) из Overpass, а при его недоступности — из файла выгрузки.

## Capabilities

### New Capabilities

- `assistant-geo`: гео-инструменты Эвала и кэш мест OpenStreetMap в PostGIS.

### Modified Capabilities

Нет.

## Impact

- Код: новый `src/lib/geo/*` с тестами, `scripts/load-osm-places.ts`, скрипт в `package.json`, `src/lib/db/database.types.ts`.
- База: новая миграция, применяется к живой базе через `npm run db:push`; таблицы заполняются скриптом.
- Внешние сервисы: nominatim.openstreetmap.org, overpass-api.de, routing.openstreetmap.de — по их правилам использования; атрибуция «© OpenStreetMap contributors, ODbL» хранится с каждой точкой.
- Поведение чата не меняется до `assistant-map-message`.
