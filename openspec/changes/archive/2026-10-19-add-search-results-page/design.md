# Design

## Context

Каталог, контракт параметров и кнопка избранного — из `add-prototype-foundation`. Next.js 16: `/search` пререндерится статически, параметры читаются на клиенте (`useSearchParams` внутри Suspense); перед кодом читать `node_modules/next/dist/docs/`.

## Goals / Non-Goals

**Goals:**
- Рабочий список, фильтры, сортировка и карта на демо-каталоге.
- Состояние страницы восстанавливается по адресу.

**Non-Goals:**
- Страница отеля (change `add-hotel-pages`), подборки на главной.
- Поиск по видимой области карты, кластеризация маркеров.

## Decisions

**Параметры адреса:** запрос — как у поиска (`destination` или `scenario`, `checkin`, `checkout`, `adults`, `children`, `rooms`); фильтры — `price_min`, `price_max`, `stars` (список через запятую), `rating` (6, 7, 8, 9), `meal` (список), `free_cancel=1`; сортировка — `sort` (`popular`, `price_asc`, `price_desc`, `rating`). Изменение фильтров заменяет адрес без новой записи истории.

**Поиск с главной:** `useHotelSearch` после валидации выполняет переход `router.push('/search?…')`. Демо-задержка ~700 мс переносится на страницу результатов (состояние загрузки «Ищем варианты…»). Невалидный или пустой запрос на `/search` показывает форму поиска с ошибками валидации.

**Карта:** `maplibre-gl`, стиль `https://tiles.openfreemap.org/styles/liberty`, атрибуция © OpenStreetMap и OpenFreeMap. Модуль карты грузится динамическим импортом на клиенте. Desktop (`lg` и шире): список и карта рядом; мобильные: переключатель «Список / Карта». Наведение или фокус на карточке подсвечивает маркер; нажатие на маркер подсвечивает и прокручивает к карточке. Ошибка загрузки стиля или тайлов — «Карта недоступна», список работает. В jsdom модуль карты подменяется моком.

**Карточка отеля:** заглушка фото, название, звёзды, рейтинг и число отзывов, расстояние до центра, бейджи «Бесплатная отмена» и питание минимального тарифа, цена «от N ₽ за M ночей», кнопка избранного, ссылка на отель.

**Пустой результат:** «Ничего не нашлось» и кнопка «Сбросить фильтры».

**Решения исполнителя (2026-10-19).**
- Модули: `src/lib/results.ts` (`runDemoSearch` по отелям каталога, `Filters`, `parseFilters`/`setFilterParams`, `applyFilters`, `SORTS`), `src/app/search/page.tsx`, `src/components/SearchResultsPage/` (`SearchResultsPage`, `HotelCard`, `FiltersPanel`, `SearchMap`, `MapUnavailable`), `src/hooks/useToday.ts`. В `src/lib/search.ts` добавлены `fromSearchParams` (обратное к `toSearchParams`), `withStartDates` (перенесён из хука) и `DEFAULT_GUESTS`; `runDemoSearch` по направлениям и `SearchResults.tsx` удалены.
- `useHotelSearch({ query, errors })` принимает стартовые значения формы и ошибки (страница результатов передаёт запрос из адреса); `submit`/`searchFor` синхронно возвращают ошибки и при валидном запросе вызывают `router.push` внутри `startTransition`; пока открывается `/search`, кнопка «Найти отель» показывает загрузку (`pending`). Ассистент при валидном варианте сразу открывает `/search`, ручная форма главной открывается только при ошибках.
- Разбор адреса: неизвестный `destination`/`scenario` — пустое направление; без дат — даты по умолчанию (завтра и послезавтра) и гости 2/0/1; некорректные числа гостей — ошибка «Проверьте количество гостей». Новый поиск со страницы («Изменить поиск») сбрасывает фильтры; смена фильтров не перезапускает демо-поиск (компонент результатов ключуется только параметрами запроса).
- Фильтры в адресе пишутся через `window.history.replaceState` (Next.js синхронизирует его с `useSearchParams`); значения по умолчанию (сортировка «популярные», пустые фильтры) в адрес не пишутся; неизвестные значения игнорируются. «Сначала популярные» — по числу отзывов, затем по рейтингу; «По рейтингу» — по рейтингу, затем по отзывам.
- Тариф карточки — самый дешёвый среди подходящих под фильтры питания и бесплатной отмены (без них — минимальный тариф отеля); фильтр цены и сортировка по цене используют его цену за ночь. Отель без подходящего тарифа не показывается.
- Раскладка: от `lg` — фильтры над списком слева и карта справа (sticky), от `xl` — три колонки (фильтры, список, карта). Ниже `lg` фильтры раскрываются кнопкой «Фильтры (N)», переключатель «Список / Карта»; карта монтируется только в режиме «Карта» (на `lg` и шире — всегда). Нажатие маркера на узком экране возвращает список и прокручивает к карточке.
- Карта: маркеры — React-порталы в элементы `maplibregl.Marker`, цена за ночь, `aria-pressed` у активного; «Карта недоступна» — при ошибке до загрузки стиля, без WebGL и при ошибке загрузки чанка карты; ошибки тайлов после загрузки стиля оставляют пробелы. Путь к воркеру задан `setWorkerUrl(new URL('maplibre-gl/dist/maplibre-gl-worker.mjs', import.meta.url))`: под Turbopack MapLibre ищет воркер рядом со своим модулем и не находит его.
- Примитивы shadcn: добавлены `checkbox` и `native-select` (сортировка — нативный `select`).

## Risks / Trade-offs

- [Размер `maplibre-gl` ~200 КБ gzip] → Только на `/search`, динамический импорт; замер JS главной и `/search` записать в proposal.md.
- [Turbopack копирует в `.next/static/media` все `.mjs` из `maplibre-gl/dist` (~5 МБ, включая dev-сборки), потому что пакет ссылается на них через `new URL(…, import.meta.url)`] → Браузер их не загружает, кроме воркера; растёт только размер деплоя.
- [Внешний сервис тайлов] → Без ключа и данных пользователя; при недоступности — сообщение.
- [Меняется поведение поиска на главной] → Delta-спецификации `manual-search` и `assistant-search`, тесты обновляются.
