## MODIFIED Requirements

### Requirement: Ответ об отеле только из данных
Ответ модели о конкретном отеле SHALL содержать только слова латиницей (от четырёх букв) из данных отеля или вопроса и только выводы, о которых говорят данные: не «беруши», «лифт», «вентилятор», «чем выше, тем тише», «обычно в отелях», «как правило» без опоры в данных. Иначе ответ SHALL отклоняться: отвечает следующая модель цепочки, затем правила. «Wi‑Fi», «SPA», «TV» и названия из данных проходят. «(no window)» называется «(без окна)».

#### Scenario: Английское слово
- **WHEN** модель пишет «лифт называется lift», а в данных такого слова нет
- **THEN** ответ отклонён, ответ даёт следующая модель или правила

#### Scenario: Этаж и тишина без данных
- **WHEN** модель пишет «Чем выше этаж, тем тише», а в данных нет оценки шума по этажам
- **THEN** ответ отклонён, ответ даёт следующая модель или правила

#### Scenario: Вывод есть в данных
- **WHEN** модель пишет «В доме есть лифт», а в данных отеля лифт назван
- **THEN** ответ принят

#### Scenario: Капсула без окна
- **WHEN** номер называется «Двухместная Capsule (no window)»
- **THEN** в данных и в ответе правил он «Двухместная Capsule (без окна)»
