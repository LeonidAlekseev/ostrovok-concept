## Why
На главной под шапкой серая полоса вместо зелёного фона героя (скриншот пользователя с iPhone: `/home/agent/header-grey-bug.jpg`, вне репозитория). Спека «Оформление шапки» уже требует прозрачную шапку на главной, но production отдаёт в HTML `<header class="absolute inset-x-0 top-0 bg-background">`: прозрачность считается по `usePathname()` в клиентском `Header`, а серверный рендер даёт не `/`. Атрибуты при гидрации React не исправляет, поэтому фон остаётся серым.

## What Changes
- Найти, почему серверный рендер `Header` в корневом layout получает не `/` на главной (и проверить страницу отеля, где по той же логике белые иконки на фото).
- Сделать прозрачность шапки независимой от гидрации: серверный HTML главной уже содержит прозрачную шапку. Предпочтительно через CSS по содержимому страницы (как `html` `has-[#hero-title]:bg-brand`), без своих CSS-файлов, только Tailwind; или другой корректный способ, который найдёт исполнитель.
- То же для страницы отеля, если там та же ошибка.
- Регрессионный тест на серверный рендер / разметку.

## Impact
- `src/components/Header/Header.tsx`, возможно `src/app/layout.tsx`, тесты шапки.
- Спека `site-header`: сценарий про серверный HTML.
