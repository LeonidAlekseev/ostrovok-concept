## Context

В базе: `geo_noise` (EEA END 2022, полосы 5 дБ, Lden и Lnight по слоям: дороги, магистрали, ж/д, магистральные ж/д, промышленность, аэропорт), RPC `hotel_geo` (полосы в точке по слоям) и `hotel_geo_features` (GeoJSON зданий и шума в радиусе), `osm_places_near` (кэш мест OSM). Карта — MapLibre со стилем OpenFreeMap (`mapSetup.ts`).

## Goals / Non-Goals

**Goals:** модуль на странице настоящего отеля из реальных данных; одна функция фактов о шуме для страницы и Эвала.

**Non-Goals:** балл «N/10», «сторона номера», экранирование зданием — данных нет, не выдумываем. Окно отеля на поиске — без модуля (только страница).

## Decisions

- **Полоса, а не число.** EEA даёт полосу (`55–59 дБ` = [55, 60)); показываем диапазон. Метода и погрешности в наборе нет — так и пишем.
- **Нет данных ≠ тихо.** Отель вне контуров (вне загруженных карт города или ниже порога картирования) — «Нет данных EEA … Это не значит, что здесь тихо».
- **Дневной уровень.** Из директивы 2002/49/EC: Lden = 10·lg(1/24·(12·10^(Ld/10) + 4·10^((Le+5)/10) + 8·10^((Ln+10)/10))). Допущение Le = Ld даёт Ld = 10·lg((24·10^(Lden/10) − 8·10^((Ln+10)/10)) / (12 + 4·√10)). Берётся слой с самой громкой Lden и его же Lnight. Диапазон дня — по углам полос: максимум из (верх Lden, низ Lnight), минимум из (низ Lden, верх Lnight); если формула в этом углу не имеет решения — второе допущение «днём не тише ночи», минимум = низ полосы Lnight. Открытые полосы (`ниже 40`, `75 и выше`) — без оценки и без графика.
- **График суток.** 48 получасов: ночь — середина полосы Lnight, день и вечер — Ld из середин полос (в пределах диапазона дня, иначе середина диапазона), переходы около 07:00 и 23:00 сглажены smoothstep на 2 ч. Подпись: иллюстрация, допущения, «Точность и монотонность не гарантируются».
- **ВОЗ.** Сравнение полосы с рекомендациями ВОЗ для Европейского региона (2018) по слою: дороги 53/45, ж/д 54/44, аэропорт 45/40 (Lden/Lnight); для промышленности рекомендаций нет — без сравнения. Это внешний опубликованный ориентир, а не оценка шума.
- **Карта.** Контуры из `hotel_geo_features` (300 м) через `GET /api/hotels/<id>/noise-map`: только слой шума, координаты до 5 знаков (~1 м), ~340 КБ без сжатия; кэш `unstable_cache` с каталогом. Полосы ниже 40 дБ не рисуются: у каждого слоя такая полоса покрывает всё вокруг и, наложившись, окрашивает громкие полосы других слоёв. Цвета — ColorBrewer RdYlGn (обычная шкала карт шума), заливка под зданиями и подписями стиля, колесо мыши не масштабирует. Атрибуция: © OpenStreetMap и © EEA, END 2022.
- **Места OSM.** `nightclub, bar, restaurant, fast_food, tram, train_station` в 200 м (до 20 на категорию), без повторов одного объекта. «Рядом нет» — только если кэш покрывает все категории, иначе «нет данных».
- **Здание.** `details.building` (уже без сомнительного здания). Высота по оценке модели EUBUCCO помечается «≈» отдельно от этажей (`heightEstimated`); ключ кэша деталей сменён на `hotel-details-v2`.
- **Эвал.** `noiseLines(noise)` — строки фактов для модели и для правила `ruleAnswer` (вопрос со словами «шум», «тих», «громк», «децибел»).

## Risks / Trade-offs

- Полоса Lden и Lnight — разные модели EEA; при близких полосах диапазон дня широкий (например, 55–69 дБ) — показываем как есть.
- Отели у аэропорта и в пригородах вне загруженной области — «нет данных EEA», хотя у EEA там могут быть контуры: загрузка шире — отдельная задача.
