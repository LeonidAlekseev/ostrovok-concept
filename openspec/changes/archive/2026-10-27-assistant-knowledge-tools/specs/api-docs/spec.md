## ADDED Requirements

### Requirement: Ответ подбора инструментами хранилища
Схема ответа `POST /api/assistant` SHALL описывать поле `findings` (ответ инструментов хранилища) и необязательные группы `groups` результата запуска; пример ответа подбора «аптека + тихо» в Валенсии SHALL проходить проверку по схеме.

#### Scenario: Пример подбора
- **WHEN** тест документа проверяет примеры
- **THEN** ответ подбора с шагами «Отели по характеристикам», «Места рядом», «Отзывы» и `findings` соответствует схеме
