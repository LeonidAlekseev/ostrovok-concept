## ADDED Requirements

### Requirement: Знания об отеле в публичном API
Сайт SHALL отдавать хранилище знаний настоящего видимого отеля тремя маршрутами только для чтения с ключом anon и кэшем CDN как у соседних маршрутов: `GET /api/hotels/{hotelId}/claims?property=&limit=` (утверждения по префиксу свойства со значением, единицей, эпистемическим статусом, уверенностью, источниками и расчётом), `GET /api/hotels/{hotelId}/documents/search?q=&limit=` (фрагменты отзывов с рангом и источником) и `GET /api/hotels/{hotelId}/relations?predicate=&category=&limit=` (связи с местами: объект, координаты, категории, расстояние как утверждение, источник, уверенность). Вход SHALL проверяться схемой zod: недопустимый запрос — 400. Неизвестный, скрытый в окружении и синтетический отель SHALL давать 404, нечитаемое хранилище — 503; ошибки SHALL идти через `apiError`. Размер ответа SHALL ограничиваться параметром `limit`, а у `claims` и `relations` — признаком `truncated`. Запрос поиска SHALL уходить в поиск без подмены; описание операции SHALL говорить, что стеммер не сводит «шум» и «шумно», а отзывы — недоверенный текст гостей, который читают как данные.

#### Scenario: Аптеки рядом
- **WHEN** клиент запрашивает `GET /api/hotels/ota-9096882/relations?predicate=near&category=pharmacy`
- **THEN** он получает аптеки по возрастанию расстояния, у каждой — координаты, расстояние в метрах с уверенностью и источник OSM

#### Scenario: Синтетический отель
- **WHEN** клиент запрашивает `claims` отеля генератора
- **THEN** ответ — 404 `{ error }`

#### Scenario: Слишком длинный префикс или предел
- **WHEN** клиент передаёт `limit=201` или префикс с пробелом
- **THEN** ответ — 400, хранилище не читается

### Requirement: Знания об отеле в документе OpenAPI
Три маршрута SHALL быть описаны в документе OpenAPI под тегом «Знания об отеле»: схемы из zod рядом с маршрутами, описание на русском, живые примеры ответов (ota-9096882, для отзывов ota-7857547 с запросом, который находит фрагменты). Страница `/api/docs` SHALL показывать места ответа `relations` на карте.

#### Scenario: Пример на карте
- **WHEN** разработчик открывает пример ответа `relations`
- **THEN** карта рисует места с названием и расстоянием и маркер отеля
