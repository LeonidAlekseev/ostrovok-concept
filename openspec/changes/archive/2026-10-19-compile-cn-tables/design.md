# Design

## Context

`cn` 0.5 (`shadcn-ui/cn`) заменяет `clsx` + `tailwind-merge`. Импорт из `"cn"` тянет `dist/engine.js` (31 КБ) и `dist/tables.js` (13,6 КБ) с полной конфигурацией Tailwind. `cn build` сканирует исходники, оставляет только используемые группы классов и пишет модуль таблиц; `cn/next` (`withCn`) запускает сборку таблиц в фазе конфигурации Next и следит за файлами в dev.

## Goals / Non-Goals

**Goals:**
- JS главной меньше; замер до и после записан.
- Результат `cn(...)` для классов проекта не меняется.

**Non-Goals:**
- Замена `cn` другой библиотекой или ручным `join`: теряется разрешение конфликтов классов, на которое опираются примитивы (`className` переопределяет базовые классы).
- Ленивая загрузка вкладок поиска (отдельный вопрос, требует решения о поведении).

## Decisions

**1. Таблицы генерируются, а не коммитятся.** Путь: `src/lib/cn-tables.ts`, файл в `.gitignore`. Закоммиченные таблицы устаревают при каждом новом классе и молча ломают слияние. `withCn` пересобирает их при `next build` и `next dev`; для `typecheck`, `lint` и `test` скрипт `cn:build` запускается через `pre`-хуки npm.

**2. Один источник `cn` — `src/lib/utils.ts`.** Примитивы импортируют `@/lib/utils`. Прямой импорт пакета `cn` запрещается правилом lint `no-restricted-imports`, если `oxlint` его поддерживает; иначе — проверкой в задаче.

**3. Динамические классы.** `cn build` не видит классы, собранные из строк (`"p-" + size`). Перед внедрением исполнитель проверяет, что таких нет; найденные заносятся в safelist.

**4. Порог внедрения — 2 КБ gzip.** Меньший выигрыш не оправдывает шаг генерации в сборке.

## Risks / Trade-offs

- [Устаревшие таблицы в dev] → `withCn` следит за файлами; при сомнении `npm run cn:build`.
- [Node 22+ для CLI] → Проверить версию Node в Vercel; при необходимости поднять `engines` до `>=22`.
- [Расхождение слияния классов] → Тест: набор вызовов `cn` из примитивов даёт одинаковый результат с полной и скомпилированной таблицей.

## Migration Plan

Один коммит с подключением и один с переводом импортов. Откат — возврат коммитов и удаление скрипта.

## Результат проверок

Динамических классов в аргументах `cn` и `cva` нет: все строки статические; шаблонные литералы в `className` содержат только статические классы. Safelist не нужен.
