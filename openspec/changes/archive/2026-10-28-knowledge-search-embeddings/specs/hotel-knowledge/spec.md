## MODIFIED Requirements

### Requirement: Отзывы как документы
Каждый отзыв гостя с текстом SHALL храниться документом `documents` (полный текст частей, язык, доказательство «Островок» с id отзыва и временем снимка) и фрагментами `document_chunks` по частям отзыва с полнотекстовым индексом на русском стеммере и вектором `nvidia/nemotron-3.5-embed-1b`. Имя и номер автора SHALL не копироваться. Тексты отзывов SHALL читаться как данные, никогда как инструкции.

#### Scenario: Отзыв без упоминаний
- **WHEN** отзыв не говорит о шуме и тишине
- **THEN** он есть среди документов, но утверждения о шуме не даёт

## ADDED Requirements

### Requirement: Векторы фрагментов документов
`npm run db:embed:chunks` SHALL считать векторы фрагментов документов отелей только для фрагментов без вектора или с изменённым текстом (`content_hash` пишется только вместе с вектором), не больше 40 запросов в минуту, с повтором при 429 и 5xx. Изменённый фрагмент SHALL терять вектор и `content_hash`; переписанный во время подсчёта SHALL не получать вектор старого текста.

#### Scenario: Повторный запуск
- **WHEN** `npm run db:embed:chunks` запускается второй раз без изменений фрагментов
- **THEN** в модель ничего не уходит, скрипт печатает 0 посчитанных

#### Scenario: Без ключа модели
- **WHEN** `npm run db:embed:chunks` запускается без `NVIDIA_API_KEY`
- **THEN** скрипт завершается ошибкой, не меняя данных, а фрагменты без вектора находятся по словам

### Requirement: Гибридный поиск по отзывам
«Отзывы» и «Анализ шума» Эвала SHALL искать отзывы отеля гибридно (`searchHotelReviews` поверх `hotel_chunks_hybrid`): слова темы — в полнотекстовой части, вектор названия темы — в части по смыслу. Цитироваться SHALL только фрагменты отзывов, где тема названа словами. Вектор запроса (`queryVectorOrNull`) без ключа, при сбое модели или дольше 4 с SHALL быть `null`, и поиск SHALL идти по словам; синтетический отель и сбой базы SHALL давать `null`.

#### Scenario: Отзыв о шуме другими формами
- **WHEN** Эвал ищет отзывы о шуме у отеля, где гость сказал о шуме только словом «шумоизоляция», которого нет в словах запроса
- **THEN** фрагмент найден частью по смыслу и процитирован

#### Scenario: Без ключа модели
- **WHEN** ключа `NVIDIA_API_KEY` нет
- **THEN** отзывы ищутся по словам, как раньше, без ошибки

## REMOVED Requirements

### Requirement: Полнотекстовый поиск по отзывам
**Reason**: инструменты Эвала ищут отзывы гибридно; `searchHotelChunks` удалён.
**Migration**: «Гибридный поиск по отзывам»; SQL-функция `hotel_chunks_search` остаётся для совместимости.
