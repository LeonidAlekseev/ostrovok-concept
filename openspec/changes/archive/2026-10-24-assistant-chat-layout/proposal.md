## Why

Пользователь прислал 2026-10-24 референсы страницы Эвала (`/home/agent/refs/assistant-chat-v2/`: `Изображение PNG.png` — компьютер, `Изображение PNG 2.png` — список чатов на телефоне, `Изображение PNG 3.png` — чат на телефоне): мультисессии и удобный чат. Ответы: 1а (на компьютере во весь экран без шапки сайта; позже весь сайт на полную ширину отдельно), 2а (параметры поездки запоминаются в текущем чате), 3а, 4б, 5а, 6 (поделиться чатом для просмотра), 7в (скрепка — отдельный change `assistant-attachments`, микрофон здесь), 8а, 9а, 10а.

## What Changes

- **Компьютер:** `/assistant` во весь экран без шапки и подвала сайта, три колонки: слева логотип, «Новый чат», поиск, список чатов, внизу карточка «AI-помощник»; в центре чат; справа «Параметры поездки», «Последние запросы», «Возможности».
- **Адреса:** у чата свой адрес `/assistant/<id>`. На телефоне `/assistant` — список чатов, `/assistant/<id>` — чат с «назад».
- **Список чатов:** поиск по названию и тексту, группы «Сегодня», «Вчера», «На прошлой неделе», «Раньше», время или дата, начало последнего сообщения, иконка по типу поездки из разбора.
- **Шапка чата:** название (карандаш — переименовать), строка «гости · даты · район», «Поделиться», меню «Переименовать», «Удалить».
- **Поделиться:** снимок чата только для чтения по ссылке `/assistant/shared/<id>`; новая таблица `assistant_chat_shares` (миграция, применяет пользователь). Делиться может вошедший пользователь; гостю — предложение войти.
- **Параметры поездки:** даты, гости, город и район из разбора текущего чата; правка сохраняется в разбор этого чата; превью карты открывает карту с отелями последнего ответа.
- **Последние запросы:** последние 5 разных сообщений пользователя из его чатов; нажатие отправляет в текущий чат.
- **Возможности:** только то, что Эвал умеет сейчас; без маршрутов, авиабилетов и виз.
- **Под ответом с отелями:** «Показать на карте», «Изменить даты», «Фильтры» (ручной поиск с условиями чата), «Другие варианты».
- **Карточки отелей в ответе:** фото, избранное, оценка со словом, район, до двух реальных свойств (парковка, вид), цена за срок, «Выбрать» — страница отеля с датами; на компьютере ряд со стрелкой, на телефоне свайп.
- **Ввод:** время под сообщениями, микрофон через распознавание речи браузера (`ru-RU`), без поддержки — кнопки нет. Скрепки нет до `assistant-attachments`.

Не входит: вложения и модель `super-vl`, сравнение отелей, OSM- и owner-агенты, остальной сайт на полную ширину.
