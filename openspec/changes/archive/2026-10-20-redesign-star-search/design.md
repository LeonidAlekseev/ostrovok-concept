# Design

- **Изображения.** `scripts/build-images.py`: небо — 1400 px по ширине и 800 px для телефона, WebP q≈70, цель ≤ 220 КБ и ≤ 90 КБ; шар — 640×640, ≤ 80 КБ. В `CREDITS.md`: «предоставлено владельцем проекта». Исходные PNG в репозиторий не кладём.
- **Фон.** `next/image` `fill` + `object-cover` (или `<picture>` с двумя размерами) под содержимым секции; `sizes` по ширине страницы. Не `priority`: блок ниже первого экрана.
- **Шар.** `MagicOrb` рисует изображение `orb.webp` с `mix-blend-screen` — чёрный фон исходника исчезает на тёмном небе. Внутри окна гадания фон тоже тёмный; если где-то фон светлый — радиальная маска `mask-radial`. Перелив CSS прежнего шара убрать, лёгкое «дыхание» свечения допустимо, при reduced motion — статично.
- **Круг и орбита.** Один SVG: окружность, 12 делений, знаки ♈…♓ (с `U+FE0E`, чтобы не стали эмодзи), эллипс орбиты, две планеты-точки; цвет — `--decor-gold`. Вращение — `--animate-*` в `@theme` (`motion-safe:`), около 120 с на оборот. `aria-hidden`.
- **Текст.** Заголовок — `bg-linear-to-b` из `--decor-gold`-оттенков, `bg-clip-text text-transparent`; выделения — новый токен `--decor-lavender`. Кнопка — существующий `Button` `shape="pill"`, градиент и золотая обводка из токенов.
- **Видео.** `starVideo.ts` грузит `orb.webp` в `Image` до начала записи (ждать `decode()`), рисует его `drawImage` с `globalCompositeOperation = 'screen'` вместо `drawOrb`; анимация видео (появление знака, искры) сохраняется. Если изображение не загрузилось — прежний нарисованный шар как запасной путь.
