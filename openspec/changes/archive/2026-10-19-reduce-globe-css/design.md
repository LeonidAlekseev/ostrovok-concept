# Design

## Context

Последний этап перевода CSS на Tailwind. Решение пользователя 2026-10-19: свой CSS заменяется на Tailwind и shadcn во всех модулях, размер CSS не ограничивает.

## Goals / Non-Goals

**Goals:**
- В `src/components` нет `*.module.css`.
- `@keyframes` объявлены в `@theme` и запускаются утилитами `animate-*`.
- `@theme` без `static`.
- Правило утилит для `translate`/`scale`/`rotate`/`box-shadow` соблюдено во всех компонентах и записано в README.
- Визуал сохраняется в пределах допустимых отклонений.

**Non-Goals:**
- Логика и рендер глобуса (Canvas 2D, `public/data/globe.json`).
- Изменение значений токенов дизайн-системы.
- Примитивы shadcn в `src/components/ui/*`: их код генерирует CLI, правило к ним не применяется.
- Порог по размеру CSS.

## Decisions

**Анимации:** `@theme { --animate-<имя>: <имя> <длительность> …; @keyframes <имя> { … } }` в `globals.css`. Задержки и параметры, которые меняются по элементам, — через утилиты (`delay-*`, `[animation-delay:…]`) или CSS-переменные в `style`.

**Правила, которые зависят от пользовательских свойств глобуса** (`--globe-x`, `--sun-angle` и т. п.), — утилиты с `var()` в произвольных значениях (`left-(--globe-x)`, `bg-[conic-gradient(…var(--sun-angle)…)]`).

**Метрика** — суммарный размер `.next/static/chunks/*.css` после `npm run build`, сырой и gzip −9; только запись.

**Скриншоты:** headless Chromium, viewport 1280×900 и 390×844, `prefers-reduced-motion: reduce`, время и `Math.random` зафиксированы, pixelmatch threshold 0.1. Глобус в двух режимах: скрыт (сравнение страницы) и показан на остановленном кадре (эффекты вокруг глобуса). Состояния: hero целиком, панель статистики, пин в hover, focus и выбранный, карточка направления (обычная, hover, выбранная), баннер, шапка, панель поиска на каждой вкладке, слот-машина в покое, в середине анимации и после остановки, ассистент с индикатором набора. Анимации сравнивать на паузе в фиксированный момент. Скриншоты кладутся вне репозитория, в `/tmp/reduce-globe-css-screenshots/{before,after,diff}`, и не коммитятся. В proposal.md записываются только методика и результат pixelmatch по кадрам.

**Проверка `static`:** после удаления убедиться, что каждый токен, на который ссылаются утилиты или `style`, присутствует в сборке.

**`static`, итог:** `static` снят без переноса токенов в `:root`. После удаления модулей значения темы во время выполнения читают только утилиты (`text-(length:--text-display)`, `rounded-sm`, `animate-*`) и `var(--font-sans)` в `globals.css` — Tailwind видит их и оставляет в сборке. Значения через `style` и `var()` в произвольных значениях (`--x`, `--y`, `--o`, `--r`, `--d`, `--globe-*`, `--card-*`, `--decor-*`, роли) — не токены `@theme`: они задаются в `style`, в классах или в `:root`. Объявления `--text-xs` … `--text-7xl` удалены: они повторяли значения Tailwind по умолчанию и нужны были только модулям. Проверка: список переменных, на которые ссылается `var()` в CSS сборки, но которые в ней не объявлены, одинаков со `static` и без него — только `--x`, `--y`, `--o`, `--r`, `--d` (задаются в `style`), `--anchor-width` (Base UI) и `--default-*` Tailwind с fallback. Из сборки выпали неиспользуемые `--breakpoint-xs/sm/lg/xl`, `--text-xl`, `--text-4xl` … `--text-7xl` и `--pin-scale` (`@property` из `Hero.module.css`).

**Порядок коммитов:** анимации в `@theme` и удаление модулей `AssistantSearch`, `RandomSearch`; `Hero`; `static`; правило утилит по компонентам; README.

## Risks / Trade-offs

- [Токены выпадут из сборки без `static`] → Проверка из Decisions и скриншоты.
- [Эффекты глобуса анимированы и плохо сравниваются попиксельно] → Остановленный кадр, `prefers-reduced-motion: reduce`.
- [Длинные строки классов в JSX] → Принято.
- [Рост CSS] → Принято решением пользователя; числа записываются.
