## Why

Запрос «Найди отели, где хороший и качественный завтрак.» давал в блоке «Отзывы» ошибку «Отзывы не искал: ни один отель не подобран». Отбор отелей по отзывам читал отзывы каждого отеля Валенсии отдельным запросом (около 200 запросов) и укладывался в 5 с лишь на быстрой базе: при нагрузке отбор не успевал, отелей не оказывалось, а блок называл причиной «ни один отель не подобран». Поиск шёл только по отзывам, хотя о завтраке говорят и описания отелей, и ответы отельеров; название «Отзывы» не отражало этого, а два способа поиска (по словам и по смыслу) были скрыты внутри одного шага.

## What Changes

- Инструмент «Отзывы» называется «Углубленный поиск» и идёт двумя видимыми шагами: «Точный поиск по словам» (FTS) и «Поиск по смыслу» (векторы); у каждого свой блок с аргументами, отелями, цитатами и источниками. Запуски пишутся в `tool_runs` под именами `deep_search_exact` и `deep_search_meaning`.
- Поиск идёт по всем документам отеля: отзывам, описаниям (новый вид документа `description` со страницы Островка) и ответам отельера (только разрешённые, `shareable`). У каждой цитаты в источниках подпись типа: «отзыв», «описание отеля», «ответ отельера»; демо-сведения помечены «демо».
- Новая функция БД `hotels_chunks_search` читает документы многих отелей одним запросом: отбор отелей укладывается в доли секунды. Вместо «ни один отель не подобран» блок различает «не успел прочитать» и «тема нигде не названа».
- Поиск отеля («найди отели, где …», «тихий отель с завтраком») сначала уточняет даты и состав, затем ищет среди отелей в пределах бюджета; вопрос о теме без слова «отель» («где хороший завтрак») отвечается сразу по всем отелям Валенсии.
- Сохранённые чаты показывают шаг «Отзывы» под новым названием «Углубленный поиск».

## Impact

- Спецификации: `assistant-search` (инструменты подбора, выбор инструментов, поиск по документам), `hotel-knowledge` (гибридный поиск), `api-docs` (пример подбора).
- Код: `src/lib/ai/knowledgeTools.ts`, `src/lib/ai/knowledgeTurn.ts`, `src/lib/db/claims.ts`, `src/lib/claimRows.ts`, `src/lib/assistant.ts`, `src/lib/assistantChats.ts`, `src/app/api/assistant/route.ts`, `scripts/hotel-features.ts`, `scripts/lib/claims-store.ts`, тесты, документация.
- Миграция `20261029200000_deep_search.sql`: вид документа `description`, функция `hotels_chunks_search`. Описания попадают в поиск после `npm run db:features` и `npm run db:embed:chunks`; пока функции в базе нет, код читает документы по отелю по одному, как раньше.
