## ADDED Requirements

### Requirement: Синтетические отели только вне production
Каталог SHALL различать настоящие отели (из выдачи Островка, `id` вида `ota-<master_id>`) и синтетические. В production каталог SHALL отдавать только настоящие отели, а направления и сценарии без видимых отелей SHALL скрываться. Вне production SHALL быть видны все отели. Синтетические данные SHALL оставаться в Supabase.

#### Scenario: Production
- **WHEN** приложение собрано для production и пользователь ищет отели
- **THEN** в выдаче, подборках, помощнике, вайбе, звёздах и «Нарисуй» только отели Валенсии из выдачи Островка

#### Scenario: Preview
- **WHEN** приложение собрано для preview или запущено `next dev`
- **THEN** видны и настоящие, и синтетические отели всех направлений

#### Scenario: API
- **WHEN** в production запрашивается `GET /api/hotels?ids=` с id синтетического отеля
- **THEN** этот отель в ответе не возвращается
