## Why

Мелкие находки исполнителей накопились в TODO (пакет 4 «small-tech-debt-4»): группы «Эвал», «Отельер», «Данные и API».

## What Changes

- Эвал: голые числа с пробелами («15 2026», «10 11 2026») не читаются бюджетом; вопрос «Стоит ли просить высокий этаж?» не уходит в поиск мест; реплика модели при разборе пожелания без вопросов («Сколько человек?» к «вдвоём»); ответ об отеле с латинским словом или советом, которых нет в данных, не принимается (следующая модель, правила); номер «(no window)» называется «без окна»; в ответ API попадает `model` — id ответившей модели.
- Поиск места по имени в кэше OSM находит «Aqua Multiespacio» по «ТЦ Aqua» (слова названия целиком).
- Отельер: посредник передаёт отельеру вопросы о трансфере из аэропорта и о балконе с видом на море; вкладка «Отельер» не показывает чат, скрытый гостем; «Мои чаты» обновляются по Realtime, а на телефоне раздел «С отельерами» стоит первым; адрес страницы Островка сохраняется при загрузке и становится ссылкой источников; `knowledge/retry` вызывает Vercel Cron.
- Данные и API: шум страницы и Эвала читается из `hotel_features.noise_facade`, а не вызовом `hotel_noise_facade` на каждый запрос; `/health` описан в OpenAPI; комментарий миграции эмбеддингов называет верную модель.
- Миграции: `hotel_features.noise_facade`, `hotelier_traveller_chat` без скрытых чатов, `ota_hotel_pages.url`, `osm_places_named` по словам.

## Impact

- Ответы Эвала, `POST /api/assistant` (поле `model`), `GET /api/hotelier/knowledge/retry` (новый, для cron), `GET /health` в документе OpenAPI, переменная `CRON_SECRET`.
- Живая БД: четыре миграции, затем `npm run db:features` (после миграций) и `npm run db:load:ota-pages` при появлении снимков.
