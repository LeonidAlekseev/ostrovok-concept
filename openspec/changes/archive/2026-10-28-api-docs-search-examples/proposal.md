## Why

`/api/docs` описывал не все виды поиска и ответов Эвала: не было семантического поиска и поиска по фото, вопросов об отеле о виде с этажа, маршрутах, «до …» и доступности, а карты примеров рисовали только `map`. Примеры шли по разным отелям.

## What Changes

- Описание `POST /api/assistant` разбито по видам: вопрос об отеле (места и маршруты, `geocode` «до …», вид с этажа, шум, отзывы и сведения отельера, доступность и запрос отельеру), подбор (по описанию, по фото `match_hotel_photos`, по характеристикам и отзывам), бронирования; сказано, чего у подбора нет (первый этаж, доступность).
- Новые живые примеры Эвала для `ota-7481548`: вид с 9-го этажа (ТЦ Aqua), закат и море с 12-го, пеший маршрут до метро, маршрут на машине до аэропорта, «сколько идти до Центрального рынка», коляска и первый этаж, отзывы, подбор по описанию, подбор по фото.
- Примеры с картой сняты по `ota-7481548`; исключение — вид из отеля (`GET /view`, пример пути к морю) остаётся у `ota-9096882`.
- `GET /api/hotels/{hotelId}/documents/search`: второй пример — слова отельера находятся по смыслу (ota-7568446); `GET /hotelier/facts`: пример — живой ответ вместо написанного вручную.
- Карта `/api/docs` рисует места виджетов Эвала (`widget.kind` `view` и `noise`).
- `npm run docs:examples` снимает все новые примеры.

## Impact

- Только документация и её страница; маршруты и ответы сайта не меняются.
