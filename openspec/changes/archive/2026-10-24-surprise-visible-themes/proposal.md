## Why
«Удиви меня» Эвала зимой выбирает тему «экзотика» (`src/lib/assistant.ts:262`, `VIBE_DESTINATIONS`), а в production у неё нет видимых городов — план выходит пустым. Решение пользователя 2026-10-24: выбирать только из тем, где есть видимые города.

## What Changes
- «Удиви меня» и случайный выбор темы берут только темы, у которых есть хотя бы один видимый город с отелями (видимость — `isVisibleHotel`); если подходящих нет — запасной вариант по видимым городам без темы.
- Сезонные предпочтения сохраняются среди подходящих тем.

## Impact
- `src/lib/assistant.ts`, тесты. Spec `assistant-search`.
