## MODIFIED Requirements

### Requirement: Уведомления и меню разделов
Меню SHALL быть `nav` «Основное меню» со ссылками «Спросить Эвал» (`/assistant`), «Искать вручную» (`/search`), «Мои поездки» (`/trips`), «Избранное» (`/favorites`), «Поддержка» (`/help`) и «API» (`/api/docs`, во всех окружениях) и пунктом «Уведомления» (кнопка с `aria-expanded`), раскрывающим внутри меню «Новых уведомлений нет» с кнопкой «Понятно», сворачивающей текст. Переход по ссылке SHALL закрывать меню.

#### Scenario: Ссылка меню
- **WHEN** пользователь выбирает «Избранное» в меню
- **THEN** меню закрывается, открывается `/favorites`

#### Scenario: Уведомления в меню
- **WHEN** пользователь выбирает «Уведомления» в меню
- **THEN** внутри меню раскрывается «Новых уведомлений нет» с кнопкой «Понятно»

#### Scenario: Документация API
- **WHEN** пользователь в любом окружении выбирает «API» в меню
- **THEN** меню закрывается, открывается `/api/docs`
