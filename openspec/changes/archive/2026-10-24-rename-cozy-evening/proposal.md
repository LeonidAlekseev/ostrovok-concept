## Why
Решение пользователя 2026-10-24: вариант вайба «Тихий вечер» переименовать в «Уютный вечер» — в блоке «Это твой вайб» на главной и в окне вайба.

## What Changes
- Подпись левого полюса первой оси вайба (`VIBE_AXES`, `src/lib/vibe.ts`) — «Уютный вечер»; карточка блока на главной (`src/components/VibeSearch/VibeSearch.tsx`) — «Уютный вечер». Название задаётся в одном месте, если карточка может брать его из `VIBE_AXES`.
- Подпись попадает везде, где выводится полюс: пары в окне, статистика итога, картинка для друзей, текст запроса поиска по смыслу и описание отеля для эмбеддингов (`src/lib/ai/documents.ts`, `vibePoles`).
- Описания отелей изменятся, поэтому векторы отелей пересчитываются: `npm run db:embed` (пересчитывает только изменённые). Если команду не разрешено выполнить — передать оркестратору, пользователь запустит сам; до пересчёта поиск по смыслу работает, но описания в базе со старой подписью.
- Комментарии, тесты, README и specs с «Тихий вечер» обновляются.

## Impact
- `src/lib/vibe.ts`, `src/components/VibeSearch/*`, `src/lib/ai/documents.ts` (комментарий), тесты (`vibe.test.ts`, `VibeSearch.test.tsx`, `actions.test.ts`, `drawMood.test.ts`), README. Specs `vibe-search`, `draw-search`.
- После `selection-to-search` (общие файлы вайба и spec `vibe-search`) и `nvidia-direct-api` (пересчёт векторов без дневного лимита OpenRouter).
