## Why
Пользователь полностью убирает из проекта маршруты путешествий: остаются только отели. Везде, где сейчас предлагается маршрут, нужно предлагать отель.

## What Changes
- **Удалить маршруты целиком:** страницу `/routes/<id>` (`src/app/routes`, `RoutePage`), карточки и витрины (`RouteCard`, `RouteShowcase`, `ReadyRoute`), данные и логику (`src/data/routes.ts`, `src/lib/routes.ts`, `src/lib/db/routes.ts`), генераторы/сиды маршрутов в `scripts`.
- **Удалить планы поездки** — они копия маршрута («Повторить маршрут»): `/trip/new`, `/trip/<id>`, `src/app/trip`, `TripPlan`, `src/lib/trip.ts`, блок «Мои планы» в `/trips` (бронирования в `/trips` остаются), Liveblocks-комнаты поездки и зависимости Liveblocks, если больше нигде не нужны.
- **Заменить маршрут на отель:**
  - глобус на главной: пины — города с отелями, карточка у пина и хаба — отель (фото/иконка, название, город, «от N ₽ за ночь»), ведёт на страницу отеля; дуги между городами убрать, если они означали маршрут;
  - главная: секция «Готовые маршруты для вас» (`PersonaCarousel`) → подборки отелей по персонам (студент, люкс, воркейшн, культура…) из каталога;
  - умный помощник Эвал: план без «готового маршрута», вместо него отели; тексты и промпты ИИ без маршрутов;
  - поиск по звёздам: результат — один отель в выбранном звёздами городе (если нет — ближайший подходящий), «Куда едем?» остаётся; видео в конце показывает отель;
  - «Нарисуй своё путешествие»: шаг 3 «Ваш отель готов!» / подбор отеля по настроению рисунка; прогресс «Подбираем отель»;
  - поиск по вайбу (`VibeSearch`): результат без маршрутов;
  - тексты помощи/FAQ, юридические, sitemap, ссылки в шапке/меню и подвале без маршрутов и планов.
- **База данных:** таблицы `routes`/`trips` в Supabase не удалять в этом change (без потери данных); код перестаёт их читать и писать. Удаление таблиц — отдельная миграция по запросу пользователя.
- Параллельно идёт change `rebrand-objektivno` (название «О!бъективно», без кнопки «Рандом» и облака). Перед PR влить свежий `origin/dev`.

## Impact
- Почти все модули главной, `StarSearch`, `DrawSearch`, `VibeSearch`, `SearchPanel/AssistantSearch`, `src/lib/assistant*`, `src/lib/ai/*`, `Trips`, `Header` (меню), `src/app/*`.
- Спеки: `routes` и `trip-plan` удаляются целиком; меняются `hero-globe`, `home-page`, `assistant-search`, `star-search`, `draw-search`, `vibe-search`, `trips`, `semantic-search`, `help-center` и др., где упоминаются маршруты.
