## Why

Пользователь (2026-10-26): `/search`, открытый с пустыми полями, должен показывать самые высоко оценённые отели. Сейчас там только пустая форма.

## What Changes

- `/search` без параметров: форма поиска остаётся пустой и без ошибок, под ней — видимые отели всех направлений по убыванию оценки гостей (без оценки — в конце), заголовок «Лучшие по оценкам гостей».
- Счётчик, фильтры, сортировка (по умолчанию — по оценке), карта и страницы работают как в обычной выдаче; без дат цены — «за ночь», как на остальных страницах без дат.
- Как только пользователь заполнил поиск, работает обычная выдача.

## Impact

- Спецификация `search-results-page`, требование «Страница результатов».
- Код: `src/components/SearchResultsPage/*` (режим без параметров), `useHotels`/каталог (запрос всех видимых отелей), тесты.
