## Решение пользователя (2026-10-21)

86б: «подключаем vercel ai sdk с openrouter provider и бесплатной моделью minimax/minimax-m3.1-flash:free». Провайдер: https://github.com/OpenRouterTeam/ai-sdk-provider (`@openrouter/ai-sdk-provider`, для `ai@^7`, Node ≥ 22, ESM).

Смена модели (2026-10-21): по умолчанию `nvidia/nemotron-3.5-lightning:free` вместо `minimax/minimax-m3.1-flash:free`. Рассуждение выключено через `providerOptions.openrouter.reasoning.effort: 'none'`, чтобы ответ укладывался в 8 с.

## Окружение

`OPENROUTER_API_KEY` (сервер), `OPENROUTER_MODEL` (необязательно). Ключ никогда не попадает в клиентский бандл (`import 'server-only'`). Без ключа — правила, как сейчас; CI без секретов зелёный.

## Контракт

- Запрос: `{ messages: {role, text}[], brief: Brief }`. Ответ: `{ brief: Brief, reply?: string, source: 'model' | 'rules' }`.
- Схема zod повторяет `Brief` из `src/lib/assistant.ts`; ответ модели проходит ту же нормализацию: неизвестный город → нет города, бюджет — целое ₽, ночи 1–30. Новые ответы дополняют понятое (`mergeBrief`-семантика), «Записал: …» и вопросы строятся прежним кодом (`describeBrief`, `nextQuestion`), чтобы поведение и тесты не разъехались.
- Системная подсказка на русском: задача, список городов и тем каталога, сегодняшняя дата, «отвечай только JSON по схеме».
- Таймаут 8 с (`AbortSignal.timeout`), одна попытка; любая ошибка → правила.

## Проверка

Юнит-тесты маршрута с моком модели (`MockLanguageModelV*` из `ai/test`): нормализация, отказ к правилам при ошибке, лимиты. Живая проверка с ключом из `.env.local`: «Хочу на море в октябре, бюджет до 70 000 ₽» и свободная фраза без ключевых слов (например «хочу туда, где тепло и можно поплавать с маской, недорого») — модель понимает тему и бюджет. Ключ не логировать.
