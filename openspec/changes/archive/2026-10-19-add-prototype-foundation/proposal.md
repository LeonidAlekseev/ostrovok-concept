# Proposal

## Why

Решение пользователя 2026-10-19: сделать шаблоны основных страниц сервиса как кликабельный прототип на демо-данных — сквозной путь «поиск → результаты → отель → тариф → оформление → подтверждение», вход, мои поездки, избранное, поддержка и юридические страницы. Сейчас в приложении одна страница (`src/app/page.tsx`), шапка встроена в `HomePage`, каталог содержит только направления и 48 «новых отелей» без номеров, тарифов и отзывов, состояния пользователя нет.

Этот change — общая основа, от которой зависят все остальные changes шаблонов страниц.

## What Changes

- **Каркас приложения:** шапка и подвал в корневом layout для всех страниц, страница 404, навигация между разделами.
- **Каталог отелей:** демо-каталог отелей по всем 37 направлениям с номерами, тарифами (питание, отмена, оплата), отзывами, координатами и описанием. Данные генерируются детерминированно из компактного описания, без больших файлов и без новых изображений в репозитории.
- **Состояние в браузере:** типизированные хранилища в `localStorage` для демо-сессии, избранного и бронирований, совместимые с пререндером.
- **Контракт параметров бронирования:** формат URL-параметров выбранного предложения (отель, номер, тариф, даты, гости), общий для страниц отеля, выбора тарифа и оформления.
- **Шапка:** «Избранное» становится ссылкой на `/favorites`, меню — навигацией по разделам; панель «Уведомления» остаётся.
- Маршруты конкретных страниц добавляют следующие changes.

## Capabilities

### New Capabilities

- `app-shell`: общий layout, подвал, 404, навигация, общая кнопка избранного.
- `hotel-catalog`: демо-каталог отелей, номеров, тарифов и отзывов; расчёт цены; контракт параметров предложения.
- `browser-state`: хранилища демо-сессии, избранного и бронирований в `localStorage`.

### Modified Capabilities

- `site-header`: панели «Избранное» и меню заменяются ссылками на разделы.

## Impact

- `src/app/layout.tsx`, `src/app/not-found.tsx`, `src/components/HomePage.tsx` (шапка уходит в layout), `src/components/Header/*`, новый `src/components/Footer/*`.
- Новые модули каталога (`src/data/*`, `src/lib/catalog*`) и состояния (`src/lib/storage*`, хуки).
- `src/data/hotels.ts` и потребители `newHotels` (глобус, «Случайность», ассистент) переходят на каталог без изменения поведения.
- Зависит от `reduce-globe-css` (общие файлы `Header`, `HomePage`): старт после его merge.
- Источник: запрос пользователя 2026-10-19, «шаблоны основных страниц».

## Замер JS главной

Методика (как в `compile-cn-tables`): `npm run build`; берутся все `<script src>` чанки из `.next/server/app/index.html`; для каждого размер в байтах и `gzip -9 -c | wc -c`; значения суммируются.

| | Чанков | Сырой, Б | gzip -9, Б |
|---|---|---|---|
| До (`6425e29`) | 7 | 881 838 | 284 344 |
| После (`b9166d7`) | 9 | 909 739 | 295 784 |
| Разница | +2 | +27 901 (+3,2 %) | +11 440 (+4,0 %) |

Основная часть прироста — чанк корневого layout с шапкой и `next/link` (34 914 Б, gzip 11 691 Б): раньше главная не использовала `next/link`, теперь он нужен для клиентских переходов между страницами прототипа. Генератор каталога попадает в чанк главной вместе с глобусом; полные отели (номера, тарифы, отзывы) строятся только по запросу `getHotel`, на главной — только краткие карточки 76 отобранных отелей и сгенерированных.
