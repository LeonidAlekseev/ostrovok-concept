# Design

## Decisions

**Отбор:** детерминированный — из каталога по условию подборки, сортировка по рейтингу, затем по цене; по одному отелю на направление, первые 4. Карточка — тот же компонент, что в результатах поиска, если он подходит по виду, иначе компактный вариант.

**Даты в ссылке:** стартовые даты формы (завтра и послезавтра) и 2 взрослых, 1 номер; до гидрации ссылка без дат.

**Раскладка:** на desktop — 4 карточки в ряд, на мобильных — горизонтальная прокрутка с snap.

**Отель не повторяется между подборками:** подборки идут по порядку («Рейтинг 9+», «Бесплатная отмена», «С завтраком», «До 8 000 ₽»); отель, уже показанный выше, в следующую не попадает. Без этого топ-рейтинговые отели повторялись бы в трёх из четырёх подборок.

**Условия по тарифам:** «Бесплатная отмена» — у отеля есть тариф с бесплатной отменой; «С завтраком» — есть тариф с завтраком или более полным питанием. Условие «До 8 000 ₽» — минимальная цена отеля за ночь.

**Цена на карточке:** «от N ₽ за ночь» — минимальная цена отеля (`priceFrom`), а не цена тарифа, по которому отобран отель.

**Карточка:** горизонтальная карточка результатов поиска не встаёт в сетку из 4 колонок, поэтому в подборках — компактная плитка `HotelTile` (фото, название, город, рейтинг, цена, избранное). Форматирование рейтинга вынесено в `formatRating` (`src/lib/format.ts`).

**Раскладка и даты:** на desktop — сетка из 4 колонок (`lg`); на mobile — горизонтальная прокрутка с `snap-x`, карточка 70 vw, но не шире 15 rem. Даты в ссылке — стартовые из `withStartDates`; до гидрации `useToday` пуст, и ссылка идёт без дат.
