## Why

У 221 реального отеля Валенсии страница собрана из выдачи Островка и дополнена генератором каталога: описание, скорость Wi‑Fi и время заезда выдуманы, отзывов и оценок по разделам нет, вместо мест рядом — заглушка. Лицензированные снимки страниц Островка (`/home/agent/hotels-data/<master_id>.json`, все 221 отеля) содержат настоящее описание, удобства по группам, правила и сборы, факты, оценки по источникам, отзывы и места рядом с координатами. Места Островка — первоисточник для Эвала о том, что рядом, и ориентиры будущего модуля «Вид из отеля».

## What Changes

- Загрузчик `npm run db:load:ota-pages -- <dir>` (`scripts/load-ota-pages.ts`): из снимка берутся только `hotel` (без контактов), `reviews`, `pois` и `rateSpecTagTranslations`; аналитика, настройки и CSP не сохраняются. Файлы — недоверенные данные: только JSON, предел размера, имя `<master_id>.json` и совпадение с отелем страницы, отель обязан быть в `ota_hotels`.
- Миграция `20261026140000_ota_hotel_pages.sql`: `ota_hotel_pages` (страница по `master_id`), `ota_pois` (места Островка один раз, точка PostGIS SRID 4326, GIST), `ota_hotel_pois` (связь отель↔место с расстоянием Островка), `ota_rate_spec_tags` (одна общая таблица переводов), представление `ota_hotel_places` (место с точкой, расстояние по прямой и азимут от отеля); `hotels.wifi_mbps` допускает `null`.
- Строка каталога реального отеля (`otaHotel`, `npm run db:rebuild:ota`): описание, время заезда и выезда и рабочая зона — со страницы; скорость Wi‑Fi неизвестна (`null`), сгенерированного описания нет.
- Страница реального отеля (и окно отеля на `/search` через `GET /api/hotels/<id>/details`): описание по частям, факты (номера, «Номера занимают N этажей (по данным отеля)», этажность здания только из EUBUCCO, год, розетки), удобства по группам Островка, дополнительные услуги и сборы, примечания отеля, оценки по источникам (Островок, TripAdvisor), все отзывы с источником, «Вид в отзывах гостей» (цитаты), «Что рядом». Контакты не показываются и не хранятся.
- Эвал на странице отеля отвечает о местах рядом, сборах за парковку и питомцев, фактах, оценках, отзывах и виде по данным страницы; текст для поиска по смыслу получает места рядом и удобства Островка; эмбеддинги обновлены.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `hotel-catalog`: данные страниц Островка в базе; поля строки настоящего отеля со страницы, без выдуманных описания и скорости Wi‑Fi.
- `hotel-page`: описание, факты, удобства, правила, оценки, отзывы и места рядом реального отеля по данным Островка.
- `assistant-search`: ответы Эвала о реальном отеле по данным его страницы, в том числе о местах рядом.

- `supabase/migrations/20261026140000_ota_hotel_pages.sql`, `src/lib/db/database.types.ts`; база: +5 МБ (167 → 172 МБ).
