## ADDED Requirements

### Requirement: Страницы Островка в базе
Снимки страниц Островка (`<master_id>.json`, элемент `__NEXT_DATA__`) SHALL загружаться командой `npm run db:load:ota-pages -- <dir>` только для отелей из `ota_hotels`: `hotel` страницы без контактов в `ota_hotel_pages`, места Островка один раз с точкой (PostGIS, SRID 4326, GIST-индекс) в `ota_pois`, расстояние Островка от отеля до места в `ota_hotel_pois`, переводы тарифных тегов в `ota_rate_spec_tags`. Аналитика, настройки и CSP страницы SHALL не сохраняться.

#### Scenario: Повторная загрузка
- **WHEN** загрузка запущена второй раз на тех же файлах
- **THEN** в таблицах те же строки, дублей мест нет

#### Scenario: Без контактов
- **WHEN** страница отеля содержит `contacts` с почтой и телефоном
- **THEN** в `ota_hotel_pages` их нет

### Requirement: Снимки как недоверенные данные
Загрузчик страниц SHALL читать файлы только как JSON: файл до 4 МБ с именем `<master_id>.json`, совпадающим с отелем страницы. Иначе загрузка SHALL останавливаться до записи.

#### Scenario: Чужой файл
- **WHEN** в папке есть файл `123.json` со страницей другого отеля
- **THEN** загрузка останавливается, ничего не записано

### Requirement: Места отеля с точкой
Представление `ota_hotel_places` SHALL отдавать место отеля с координатами, расстоянием Островка, расстоянием по прямой и азимутом от точки отеля (0–359°).

#### Scenario: Азимут
- **WHEN** запрошены места отеля Валенсии
- **THEN** у каждого места есть широта, долгота, `distance_m`, `straight_m` и `bearing_deg` от 0 до 359

### Requirement: Строка настоящего отеля со страницы
У отеля `ota-*` описание, время заезда и выезда и наличие рабочей зоны (`workstation` в удобствах номеров) SHALL браться со страницы Островка (`npm run db:rebuild:ota`); HTML разметка описания SHALL сниматься. Скорость Wi‑Fi такого отеля SHALL быть неизвестной (`null`): она не показывается, а фильтр «Wi‑Fi от N» такой отель не проходит. Без страницы описание SHALL быть пустым, а не сгенерированным.

#### Scenario: Описание со страницы
- **WHEN** после загрузки страниц выполнен `npm run db:rebuild:ota`
- **THEN** у каждого отеля Валенсии описание из `descriptionStruct` Островка и время заезда из его правил

#### Scenario: Без скорости Wi‑Fi
- **WHEN** открыта страница отеля Валенсии
- **THEN** строки «Wi‑Fi N Мбит/с» нет

## MODIFIED Requirements

### Requirement: Только данные Островка у настоящих отелей
У отеля из выдачи Островка (`ota-*`) SHALL быть все типы номеров из данных Островка: с тарифом — с ценой, без тарифа — без цены и бронирования с пометкой «Нет цены на выбранные даты». Сгенерированных отзывов, оценок по разделам и фото гостей у такого отеля SHALL не быть; рейтинг и число отзывов — из данных Островка, отзывы и оценки по разделам — только со страницы Островка. Отзывы `ota-*` SHALL не попадать в текст для поиска по смыслу.

#### Scenario: Все типы номеров
- **WHEN** открыта страница отеля Валенсии, у которого в данных Островка 18 типов номеров и тарифы на 3 из них
- **THEN** на странице 18 номеров, у трёх цены, у остальных «Нет цены на выбранные даты»

#### Scenario: Без сгенерированных отзывов
- **WHEN** открыта страница оценённого отеля Валенсии без отзывов на странице Островка
- **THEN** виден рейтинг Островка и «Отзывы появятся позже», списка отзывов нет

#### Scenario: Синтетический отель
- **WHEN** в preview открыт синтетический отель Праги
- **THEN** отзывы и номера как прежде

### Requirement: Номера настоящих отелей из тарифов
У отеля из выдачи Островка (`ota-*`) SHALL быть только номера из тарифов выдачи Островка; справочник `room_groups` SHALL использоваться только как описание вида номеров, а не как список номеров. Сгенерированных отзывов, оценок по разделам и фото гостей у такого отеля SHALL не быть; рейтинг и число отзывов — из данных Островка, отзывы и оценки по разделам — только со страницы Островка. Отзывы `ota-*` SHALL не попадать в текст для поиска по смыслу.

#### Scenario: Номера из тарифов
- **WHEN** открыта страница отеля Валенсии, у которого 1 тариф и 182 записи в `room_groups`
- **THEN** на странице 1 номер с ценой, записей справочника среди номеров нет

#### Scenario: Без сгенерированных отзывов
- **WHEN** открыта страница оценённого отеля Валенсии без отзывов на странице Островка
- **THEN** виден рейтинг Островка и «Отзывы появятся позже», списка отзывов нет

#### Scenario: Синтетический отель
- **WHEN** в preview открыт синтетический отель Праги
- **THEN** отзывы и номера как прежде
