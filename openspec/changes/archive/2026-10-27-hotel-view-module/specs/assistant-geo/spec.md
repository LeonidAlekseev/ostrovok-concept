## ADDED Requirements

### Requirement: Вид из окна в ответе Эвала
Эвал в чате настоящего отеля SHALL отвечать на вопросы «видно ли море / закат / место из окна» той же проверкой, что и раздел «Вид из отеля», шагами: высота здания (EUBUCCO), линии взгляда. Ответ SHALL давать для каждой цели одну из трёх формулировок с причиной и оговорку о допущениях; без надёжной высоты здания — «Недостаточно данных».

#### Scenario: Видно ли море
- **WHEN** пользователь спрашивает «Видно ли море из окна?», а линия к берегу свободна
- **THEN** Эвал отвечает «• Море (берег в 4,4 км, азимут 110° (восток)): вероятно видно.» с оговоркой о допущениях

### Requirement: Места для вида через гео-инструменты
Для вида места Эвал SHALL брать места Островка этого вида, затем `nearbyPlaces` OpenStreetMap в 3 км; для места по названию — место из ориентиров страницы, иначе `geocode`; линия до каждого найденного места SHALL проверяться той же функцией.

#### Scenario: Видно ли больницу
- **WHEN** пользователь спрашивает «Видна ли больница из номера?», а у отеля есть место Островка «Больница»
- **THEN** Эвал проверяет линию до него и называет один из трёх итогов с причиной

### Requirement: Этаж из вопроса
Этаж, названный в вопросе о виде («с 3 этажа»), SHALL учитываться; без него вид считается с верхнего этажа. Закат SHALL браться на дату заезда, иначе на сегодня.

#### Scenario: Закат с третьего этажа
- **WHEN** пользователь спрашивает «А с 3 этажа закат видно?»
- **THEN** вид считается с 3-го этажа, ответ называет время и азимут заката и итог
