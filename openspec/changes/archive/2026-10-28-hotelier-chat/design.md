## Context

Чаты Эвала (`assistant_chats`/`assistant_messages`) — личные чаты путешественника с ассистентом, у гостя они в браузере. Чат с отельером другой: у него две стороны с разными правами, и он должен жить в базе, чтобы отельер его видел. Поэтому это отдельные таблицы, а не роль `owner` в чатах Эвала: ту роль вторая часть использует для уведомления исходного чата Эвала об ответе отельера.

## Decisions

- **Право отельера — одна функция.** `is_hotelier_of(hotel_id)` (security definer) смотрит профиль: `all_hotels` или строка `hotelier_hotel_access`. Все политики и функции зовут её; демо-отельеру не нужны строки на каждый отель.
- **Писать сообщения можно напрямую под RLS, но браузер пишет через маршруты.** Политики пускают только «себя»: путешественник — `sender = 'user'` в своё обращение, отельер — `sender = 'hotelier'` в обращения своих отелей; `ai_assistant` нет ни у кого, кроме сервера. Ограничения, которые нельзя обойти прямым запросом к PostgREST (закрытое обращение, 20 сообщений автора в минуту), — в триггере; маршруты добавляют лимит по IP и валидацию.
- **Состояние обращения меняют только функции.** У `authenticated` нет `update` на обращения: последнее сообщение и счётчики ведёт триггер, прочтение — `hotelier_conversation_read`, статус — `hotelier_conversation_status` (отельер: open/resolved/closed; путешественник: только closed; закрытие отменяет ждущие запросы).
- **Одно открытое обращение путешественника к отелю** (частичный уникальный индекс). После закрытия следующее сообщение начинает новое; параллельный старт находит обращение соседа по `23505`.
- **Гость для отельера — «Гость».** В таблицах нет имени и почты путешественника, панель не читает `profiles`. `user_id` (uuid) RLS по колонкам не прячет, но интерфейс его не показывает.
- **Realtime — postgres_changes с RLS.** Канал на каждое обращение и на список, со своим именем; подписка снимается при уходе компонента или смене обращения. Сообщение, пришедшее и по ответу маршрута, и по Realtime, встаёт в ленту один раз (`addMessage` по id).
- **Демо-отельер — тем же `signInDemo`.** Второй аргумент `account`; секреты свои, без отката на путешественника. Вход отельера всегда открывает `/hotelier`.

## Risks / Trade-offs

- RLS-подписки Realtime проверяют политику (и `is_hotelier_of`) на каждое событие — для демо-нагрузки достаточно.
- Лимит в триггере считает сообщения автора за минуту запросом по индексу `(author_id, created_at)`; это дешёвая, но не строгая защита от гонки двух параллельных вставок.
