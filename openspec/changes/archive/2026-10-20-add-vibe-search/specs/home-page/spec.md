## MODIFIED Requirements

### Requirement: Состав и порядок секций
Страница SHALL рендерить по порядку: шапку, hero (`h1` «Найди свой уголок»), секцию поиска `#search` (aria-label «Поиск отелей»), секцию популярных направлений `#ideas`, секцию поиска вайба `#vibe`, секцию поиска по звёздам `#stars`, секцию подборок `#collections` и баннер `#explore`. Документ SHALL иметь `lang="ru"`, title «Островок! — бронирование отелей» и `theme-color` `#a5e87b`.

#### Scenario: Якоря секций
- **WHEN** пользователь переходит по ссылке `#search`, `#ideas`, `#vibe`, `#stars`, `#collections` или `#explore`
- **THEN** страница прокручивается к соответствующей секции

#### Scenario: Статический пререндер
- **WHEN** выполняется `npm run build`
- **THEN** главная страница пререндерится статически без переменных окружения
