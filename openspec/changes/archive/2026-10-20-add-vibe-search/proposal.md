# Proposal

## Why

Запрос пользователя 2026-10-20: блок «Поиск вайба» на главной перед «Найти по звёздам». Блок выглядит как противопоставление «Тихий вечер» vs «Шумная вечеринка» с кнопкой «Найти свой вайб». В модальном окне пользователь выбирает между двумя противоположностями или нажимает «Не могу выбрать»; в конце — статистика вайба, картинка для соцсетей с логотипом «Островок!» и слоганом «Найди свой уголок» и список отелей под настроение.

## What Changes

- Секция `#vibe` перед `#stars`: две половины «Тихий вечер» и «Шумная вечеринка» с «vs» посередине и кнопка «Найти свой вайб».
- Модальное окно «Поиск вайба»: 7 пар противоположностей по одной на экран, кнопка «Не могу выбрать», прогресс «N из 7», «Назад».
- Итог: название вайба, статистика по осям в процентах, картинка 1080×1350 для отправки, 6 отелей под настроение из разных городов.
- Расчёт в `src/lib/vibe.ts`; картинка и отправка — через `src/lib/shareMedia.ts` из `add-star-search`; карточки — `HotelTile` из `redesign-hotel-tile`.

## Capabilities

### New Capabilities

- `vibe-search`: блок, окно, расчёт вайба, картинка, подбор отелей.

### Modified Capabilities

- `home-page`: секция `#vibe`.

## Impact

- `HomePage.tsx`, новые `src/components/VibeSearch/`, `src/lib/vibe.ts`.
- Зависит от `redesign-hotel-tile` (`HotelTile`) и `add-star-search` (`shareMedia.ts`, порядок секций главной).
- Без новых зависимостей.

## Замер JS главной

Сумма gzip (уровень 9) JS-чанков, на которые ссылается пререндеренный `/` (`.next/server/app/index.html`), `npm run build`:

| Сборка                     | Чанков | Без сжатия | gzip     |
| -------------------------- | ------ | ---------- | -------- |
| До: `origin/dev` 2a16096   | 16     | 895,2 КБ   | 294,9 КБ |
| После: `add-vibe-search`   | 16     | 898,5 КБ   | 295,4 КБ |

Главная выросла на 3,4 КБ без сжатия и 0,6 КБ gzip — это секция `#vibe`. Окно «Поиск вайба» с расчётом, итогом и картинкой (`next/dynamic`, `ssr: false`) — отдельный чанк 26,2 КБ / 9,9 КБ gzip, который загружается по первому нажатию «Найти свой вайб».
