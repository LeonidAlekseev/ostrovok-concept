## Context

`POST /api/assistant` сейчас ведёт только подбор: разбор пожелания (`understandWish`), уточняющие вопросы и план с отелями (`runTurn`). Чаты (`src/lib/assistantChats.ts`) хранят разбор в `brief` (`jsonb`), данные сообщения в `data` (`jsonb`). Данные отеля на сервере: `loadHotelSummaries`, `loadHotelFeatures` (`src/lib/db/`), номера и цены — каталог (`src/lib/catalog.ts`, `src/lib/rates.ts`).

## Goals / Non-Goals

**Goals:** вопрос об отеле с ответом из его данных; общие знания модели только с пометкой; один чат, видимый и на странице отеля, и в `/assistant`.

**Non-Goals:** данные мест рядом, новые таблицы, вложения, сравнение отелей.

## Decisions

1. **Контекст отеля в разборе:** `brief.hotelId` (строка id отеля). `normalizeBrief` его сохраняет и проверяет по каталогу; без миграции. Альтернатива — колонка `hotel_id` — отклонена: лишняя миграция ради одного поля.
2. **Режим ответа:** при `brief.hotelId` маршрут не задаёт уточняющих вопросов и не строит план, а вызывает `answerAboutHotel` (`src/lib/ai/hotelAnswer.ts`). Даты чата, если есть, дают номера и цены; без дат — номера без цен и подсказка выбрать даты.
3. **Ответ модели — структурированный:** `{ answer: string, unverified?: string }` через `Output.object`. Промпт: `answer` только из переданных данных, всё прочее — в `unverified`; если данных нет, сказать это в `answer`. Сообщение хранит `data.unverified`, лента показывает его отдельным абзацем с меткой «Не проверено».
4. **Правила без модели:** номера (из каталога на даты), парковка и питомцы (из свойств и удобств). «Что рядом?» и свободный вопрос без модели — честный отказ.
5. **Один чат отеля на устройство/аккаунт:** страница отеля ищет последний чат с этим `hotelId` и продолжает его; если нет — создаёт при первом вопросе (пустой чат не сохраняется). Мини-чат показывает последние сообщения этого чата и использует тот же `useChats`-слой хранения.
6. **Раскладка:** компонент `HotelAssistant` в правой колонке (`aside`, место из `hotel-page-redesign`) и в `SheetContent` `MobileBooking` под `BookingCard`. Лента мини-чата ограничена по высоте со своей прокруткой.

## Risks / Trade-offs

- Модель может выдать непроверенное за факт → промпт плюс тест на разбор схемы; правила не используют общие знания.
- Один `useChats` на две страницы → синхронизация через то же хранилище; у гостя `localStorage` уже общий.
- Лимит запросов NVIDIA (40 в минуту) общий с подбором → тот же `allowRequest`.
