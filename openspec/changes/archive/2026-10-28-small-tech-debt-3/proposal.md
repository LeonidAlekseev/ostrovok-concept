## Why

Мелкие находки исполнителей накопились в TODO (пакет 3 «small-tech-debt-3»).

## What Changes

- «Отели по характеристикам» говорит «данные неполные», если часть чтений выбранных отелей не ответила.
- Правила ответа об отеле отвечают на все темы вопроса (питомцы, парковка, шум, места, номера), а не только на первую.
- Отдельный лимит вопросов об отеле включается только для отеля, который знает каталог.
- Сводка «Вида» не называет ник автора отзыва.
- `serviceClient` в кэше мест не запоминает отсутствие ключа навсегда; «км от центра» в документах — через `kmFromCentre`.
- Примеры `/api/docs` для `claims` сняты заново (noise-estimate-v2).

## Impact

- Ответы Эвала и лимит `POST /api/assistant`; схема API не меняется.
