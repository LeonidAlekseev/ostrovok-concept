# Design

## Context

`fix-default-search-dates` (архив) выбрал схему: первый рендер с пустыми датами, затем `useEffect` ставит заезд на завтра и выезд через ночь. Схема защищает от hydration mismatch, потому что страница пререндерится в день сборки. Её цена — синхронный `setState` в эффекте и предупреждение `react(set-state-in-effect)` (`src/hooks/useHotelSearch.ts:43`).

## Goals / Non-Goals

**Goals:**
- `npm run lint` без предупреждений.
- Стартовые даты по-прежнему от текущего дня; гидрация без расхождения разметки.
- Выбор дат пользователем, ошибки валидации и запуск поиска работают как раньше.

**Non-Goals:**
- Изменение правил валидации дат, лимита 30 ночей, календаря.
- Изменение публичного API хука (`query`, `setDates`, `run` и других полей).

## Decisions

**1. «Сегодня» — внешний источник через `useSyncExternalStore`.**
`getServerSnapshot` возвращает пустую строку, `getSnapshot` — `todayIso()`. При пререндере и гидрации React берёт серверный снимок, затем перерисовывает компонент с клиентским. Это штатный механизм React для значений, которые на сервере и клиенте различаются. Альтернативы: `// oxlint-disable` над эффектом отвергнута — прячет предупреждение, не убирая лишний рендер; ленивый инициализатор `useState` отвергнут — даёт hydration mismatch в день, отличный от дня сборки.

**2. Даты в `query` вычисляются при рендере.**
State хранит даты, выбранные пользователем (пустые до первого выбора). Если их нет, `query.checkIn` и `query.checkOut` берутся как стартовые от «сегодня»: заезд завтра, выезд через ночь. Пока «сегодня» пустое (пререндер), даты пустые, как сейчас.

**3. `run` получает уже вычисленный `query`.**
Валидация и поиск работают с тем же объектом, что видит форма; пустые даты до гидрации не меняют поведение, потому что поиск без JS не работает.

## Risks / Trade-offs

- [Подписка `subscribe` не сообщает о смене дня] → Принято: сейчас дата тоже не обновляется на открытой вкладке; `getSnapshot` вызывается при каждом рендере и вернёт новый день при следующем.
- [Регрессия в `SearchPanel.test.tsx` и тестах формы] → Прогнать все тесты; добавить тест, что после монтирования заезд — завтра, выезд — через ночь.

## Migration Plan

Чистое клиентское изменение. Откат — возврат коммита. Проверка: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`; в `npm run start` нет hydration warnings в консоли, форма показывает завтрашний заезд.
