## Why
В production виден один город (Валенсия, #192), а подборка вайба и «Нарисуй свой отдых» берёт по одному отелю на город (`onePerCity`, `src/lib/vibe.ts:258`; вызовы — `vibeHotels` и `src/components/VibeSearch/actions.ts:41`). В итоге подборка — 1 отель вместо 6. Решение пользователя 2026-10-24: если городов меньше шести, добирать подборку отелями из тех же городов.

## What Changes
- Подборка: сначала лучший отель каждого города (как сейчас), затем, пока отелей меньше 6, — следующие по порядку из уже взятых городов. Порядок и детерминизм без модели сохраняются.
- Работает одинаково для поиска по смыслу и расчёта по осям, для вайба и «Нарисуй» (общая функция).

## Impact
- `src/lib/vibe.ts` (`onePerCity` → заполнение до 6), `src/components/VibeSearch/actions.ts`, тесты `vibe.test.ts`, `actions.test.ts`. Spec `vibe-search`.
