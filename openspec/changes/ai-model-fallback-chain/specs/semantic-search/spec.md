## MODIFIED Requirements

### Requirement: Модели через API NVIDIA
Эмбеддинги, реранк и языковые модели помощника SHALL вызываться через API NVIDIA с ключом `NVIDIA_API_KEY` из секретов сервера. Текст SHALL обрабатывать цепочка `nemotron-3.5-lightning` → `nemotron-3.5-bolt-e4b` → `minimax-m3.1-flash` с таймаутом на модель в пределах общего срока ответа. Без ключа или если ни одна модель не ответила, SHALL работать прежний запасной путь без модели. Скрипты загрузки векторов SHALL соблюдать лимит 40 запросов в минуту.

#### Scenario: Ключ есть
- **WHEN** задан `NVIDIA_API_KEY` и пользователь пишет помощнику
- **THEN** запрос уходит в API NVIDIA, ответ — по смыслу

#### Scenario: Нет ключа
- **WHEN** `NVIDIA_API_KEY` не задан
- **THEN** помощник и вайб работают по правилам без сообщения об ошибке

#### Scenario: Лимит
- **WHEN** `db:embed` получает ответ 429
- **THEN** скрипт ждёт и повторяет запрос, не теряя отели

#### Scenario: Запасная текстовая модель
- **WHEN** `nemotron-3.5-lightning` не ответила за свой таймаут
- **THEN** ответ даёт `nemotron-3.5-bolt-e4b` в пределах общего срока
