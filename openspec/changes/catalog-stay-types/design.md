## Решения

- Каталог читается из Supabase (`catalog-from-supabase`); генератор остаётся источником `db:seed`, детерминизм сохраняется. Существующие отели не меняются (те же `id`, цены, отзывы) — новые объекты добавляются отдельными `id`.
- Звёзды: хостелы 1–2, апартаменты и виллы — без звёзд в интерфейсе (колонка `stars` хранит значение для сортировки; в спеке «звёзды 1–5» остаётся для отелей). Если схема требует `stars`, решить без нарушения `check`.
- Цена за ночь: хостел — кровать/номер дешевле отелей города; вилла — дороже, вместимость 6–10.
- Wi‑Fi: хостел 30–100, отель 50–300, апартаменты 100–500, вилла 50–200 Мбит/с; рабочая зона — у части отелей и апартаментов.
