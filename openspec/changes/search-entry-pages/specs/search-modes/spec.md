## ADDED Requirements

### Requirement: Страница Эвал
Страница `/assistant` SHALL показывать чат с ассистентом Эвал на светлом фоне страницы, без глобуса. Диалог SHALL сохраняться после перезагрузки страницы.

#### Scenario: Открытие страницы
- **WHEN** пользователь открывает `/assistant`
- **THEN** виден чат Эвал с полем ввода

#### Scenario: Перезагрузка
- **WHEN** пользователь написал Эвал и перезагрузил `/assistant`
- **THEN** диалог на месте

### Requirement: Пустая страница ручного поиска
Страница `/search` без параметров SHALL показывать ручную форму без ошибок валидации; ошибки SHALL появляться только после отправки формы.

#### Scenario: Открытие без параметров
- **WHEN** пользователь открывает `/search` из меню
- **THEN** видна пустая форма без сообщений об ошибках
