# Design

- **«от».** Найти все `от ` перед `formatPrice`/суммой (`grep -rn "от {\|от \${\|>от " src`). Убрать приставку, подписи периода оставить. В `aria-label` маркера — тоже.
- **Без отмены.** После генерации отелей направления отсортировать по `id` и пометить каждый второй (`index % 2 === 1`) как «невозвратный»: при построении номеров `cancellation` всех тарифов → `{ kind: 'non-refundable' }`. Ровно половина каталога (204 → 102), в каждом направлении с 2+ отелями есть оба вида. Цены и id тарифов не меняются.
- **Данные.** Подборка «Бесплатная отмена» берёт отели с гибким тарифом — проверить, что в ней по-прежнему 4 отеля из разных городов. Тесты, которые полагались на бесплатную отмену у конкретного отеля (оформление, поездки, отмена), перевести на отель с гибким тарифом, а не ослаблять.
