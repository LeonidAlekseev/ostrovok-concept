## Цвет → оси вайба
Оси из `VIBE_AXES`: evening (−1 тихий вечер, +1 вечеринка), place (−1 море, +1 город), size (−1 бутик, +1 большой), leisure (−1 спа, +1 гулять), food (−1 завтрак в номер, +1 ужин в новом месте), budget (−1 без трат, +1 лучшее), location (−1 подальше, +1 в центре).

Стартовая таблица (исполнитель может уточнить, но обязан покрыть тестами):
| Цвет | Подпись | Вклад |
|---|---|---|
| синий | Море и покой | place −1, evening −1 |
| бирюзовый | Спа и вода | leisure −1 |
| зелёный | Природа и тишина | location −1, size −1 |
| жёлтый | Солнце и веселье | evening +1 |
| оранжевый | Приключения | leisure +1, food +1 |
| красный | Страсть и ужины | food +1, evening +1 |
| фиолетовый | Ночь и город | place +1, leisure +1 |
| золотой | Роскошь | budget +1, size +1 |
| серый | Мегаполис | place +1, location +1 |
| коричневый | Уют и экономия | budget −1, size −1 |

Счёт: для каждого цвета — доля закрашенных пикселей (считать по штрихам: длина × толщина, а не по `getImageData`, чтобы логика была чистой и тестируемой). Сумма вкладов по оси, взвешенная долями; |сумма| < 0,15 → 0, иначе знак. Чистая функция `drawAnswers(strokes) → Answer[]` в `src/lib/drawMood.ts`.
