## ADDED Requirements

### Requirement: Пустое состояние со ссылками на поиск
Пустая страница «Избранное» SHALL показывать ссылки «Спросить Эвал» (`/assistant`) и «Искать вручную» (`/search`).

#### Scenario: Пусто
- **WHEN** пользователь открывает «Избранное» без записей
- **THEN** видны «Спросить Эвал» и «Искать вручную», ссылки «Найти отель» нет
