# Design

- **Гости без дат.** `setStay` без дат пишет в адрес только `adults`/`children`/`rooms`; `parseStayParams` уже возвращает `null` без дат — гостей читать отдельной функцией (`parseGuestParams`), если её нет.
- **Меню.** Пункты: «Поиск отелей», «Мои поездки», «Избранное», «Уведомления», «Аккаунт»/«Войти», «Поддержка». «Уведомления» закрывает меню и открывает панель уведомлений (тот же `Popover`, состояние поднять в `Header`). «Аккаунт» у вошедшего закрывает меню и открывает меню аккаунта; у гостя — ссылка «Войти» на `/login`.
- **Ассистент.** `affordable ?? cheapest`, где `cheapest` — минимальный `stayTotal`.
- **Лента.** `tabIndex={-1}` на прокручиваемой ленте (Chromium делает прокручиваемые области фокусируемыми).
