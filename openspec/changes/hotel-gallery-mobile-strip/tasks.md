## 1. Лента фото на телефоне

- [ ] 1.1 Уже `md` — лента фото одной высоты (около 240 px, подобрать по 360–430 px), ширина фото — по пропорциям (есть ли размеры у фото в данных — проверить; иначе по реальному изображению), без обрезки
- [ ] 1.2 Только горизонтальная прокрутка: без вертикальной прокрутки внутри ленты (`overflow-y-hidden`, `touch-action`), вертикальный свайп прокручивает страницу
- [ ] 1.3 Лента до краёв экрана (`-mx-(--page-x)`), отступ внутри ленты, первое фото по линии контента
- [ ] 1.4 Плоско: без теней и градиентов; счётчик «N / M» и открытие мозаики по нажатию сохраняются; сгенерированные фото (заглушки) — разумная пропорция, плашка generated на месте
