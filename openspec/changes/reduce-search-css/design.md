# Design

## Context

Продолжение `reduce-page-css` (архив). Метод и метрики те же.

## Goals / Non-Goals

**Goals:**
- Модули поиска переведены на Tailwind, остаток модулей — только то, что Tailwind не выражает.
- Политика `translate`/`scale`/`shadow` записана в README и соблюдена в изменённых файлах.
- gzip CSS сборки растёт не больше чем на 2 %.

**Non-Goals:**
- `Hero`, `globals.css`, токены дизайн-системы.
- Приведение к политике файлов вне scope (сделает `reduce-globe-css`).
- Изменение разметки и поведения сверх замены классов.

## Decisions

**Метрика** — суммарный размер `.next/static/chunks/*.css` после `npm run build`, сырой и gzip −9 склеенного файла.

**Скриншоты:** headless Chromium, viewport 1280×900 и 390×844, `prefers-reduced-motion: reduce`, глобус скрыт, время и `Math.random` зафиксированы, pixelmatch threshold 0.1. Состояния: панель поиска на каждой вкладке, поле направления с открытыми подсказками, календарь с выбранным диапазоном, поповер гостей, ошибки валидации, результаты поиска, слот-машина в покое и после прокрутки, ассистент с ответом. Скриншоты кладутся вне репозитория, в `/tmp/reduce-search-css-screenshots/{before,after,diff}`, и не коммитятся. В proposal.md записываются только методика и результат pixelmatch по кадрам. Порт сервера для съёмки — из задания исполнителю.

**Порядок:** `SearchForm` (с полями), `SearchPanel`, `AssistantSearch`, `RandomSearch`. Каждый модуль — отдельный коммит.

## Risks / Trade-offs

- [Анимации слот-машины не выражаются утилитами] → Оставить `@keyframes` в модуле.
- [Потеря hover, focus и `data-*`-состояний] → Снимать состояния на скриншотах.
- [Рост gzip выше 2 %] → Остановиться и эскалировать с замерами.
