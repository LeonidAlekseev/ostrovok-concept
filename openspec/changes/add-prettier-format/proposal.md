# Proposal

## Why

Prettier есть в конфиге репозитория, но не в зависимостях и скриптах. Стиль кавычек в JSX разный: `AssistantSearch.tsx`, `RandomSearch.tsx`, `Hero.tsx` используют `'` в атрибутах. Без общего форматтера такие расхождения возвращаются.

## What Changes

- Добавить `prettier` в devDependencies.
- Добавить скрипты `format` (запись) и `format:check` (проверка).
- Прогнать форматирование по проекту одним отдельным коммитом.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Изменение касается только инструментов и стиля кода, поведение не меняется (`skip_specs: true`).

## Impact

- `package.json`, lockfile.
- Все файлы в `src/`, затронутые форматированием. Диф большой, поэтому форматирование идёт отдельным коммитом.
- Пересечение с незавершённым `migrate-composite-components`: его правки в JSX тоже будут перформатированы. Порядок: либо форматирование до миграции, либо после неё.
