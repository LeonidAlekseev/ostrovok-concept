# Design

## Decisions

**FAQ:** 16–24 вопроса в 4 категориях; поиск — без учёта регистра и «ё/е» по вопросу и ответу, обновляет список при вводе; ничего не найдено — «Ничего не нашлось» и ссылка на форму обращения. Аккордеон — shadcn на Base UI (`npx shadcn@latest add accordion`). Якорь у каждого вопроса (`/help#<id>`) раскрывает его при открытии.

**Форма обращения:** проверка обязательных полей и email; отправка — «Обращение отправлено (демо): ответ придёт на <email>», без сети и без сохранения.

**Юридические страницы:** общий компонент — заголовок, дата обновления, демо-пометка, оглавление по `h2` с якорями, разделы. Тексты нейтральные, без реальных реквизитов. Cookie: перечислить ключи `ostrovok:v1:*` и их назначение; сторонних cookie и аналитики нет; тайлы карты загружаются с OpenFreeMap.

**Статика:** все страницы пререндерятся статически; `metadata` с заголовком страницы.
