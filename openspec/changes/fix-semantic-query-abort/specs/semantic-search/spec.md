## ADDED Requirements

### Requirement: Общий запрос вектора
Одновременные поиски с одинаковым текстом SHALL делить один запрос вектора к модели. Отмена или таймаут одного поиска SHALL прерывать только этот поиск: остальные поиски с тем же текстом SHALL получить вектор и пройти по смыслу.

#### Scenario: Первый поиск отменён
- **WHEN** два поиска с одинаковым текстом идут одновременно и первый отменён до ответа модели
- **THEN** второй поиск получает вектор и возвращает результат по смыслу, а не по правилам

#### Scenario: Запрос модели не удался
- **WHEN** общий запрос вектора завершился ошибкой
- **THEN** вектор не кешируется, следующий поиск с тем же текстом запрашивает модель снова
