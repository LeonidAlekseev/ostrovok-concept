## Why
`queryVector` (`src/lib/ai/semantic.ts`) хранит ожидающий вектор запроса, чтобы одновременные поиски с теми же словами делили один запрос к модели. Но запрос к модели получает `abortSignal` первого поиска. Если первый поиск отменён (пользователь ушёл, сработал его таймаут), общий промис отклоняется, и второй поиск с теми же словами уходит в запасной путь по правилам, хотя сам не отменялся.

## What Changes
- Общий запрос вектора не зависит от сигнала отдельного поиска: у него свой таймаут `SEMANTIC_TIMEOUT_MS`.
- Каждый поиск ждёт общий вектор со своим сигналом: отмена или таймаут поиска прерывают только его ожидание.
- Неудачный общий запрос по-прежнему не кешируется.

## Impact
- `src/lib/ai/semantic.ts`, `src/lib/ai/semantic.test.ts`.
- Spec `semantic-search`: добавляется требование об общем запросе вектора.
