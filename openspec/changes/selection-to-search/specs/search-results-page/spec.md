## ADDED Requirements

### Requirement: Подборка отелей
Страница `/search` с параметром `hotels` SHALL показывать только перечисленные отели (неизвестные и скрытые пропускаются) с заголовком по источнику `from` и `pick`: «Подборка по вашему вайбу: <архетип>», «Подборка звёзд для <знак>», «Подборка по вашему рисунку: <настроение>», иначе «Подобранные отели». Фильтры, сортировка, карта и страницы SHALL работать только по отелям подборки.

#### Scenario: Подборка вайба
- **WHEN** открыт `/search?hotels=a,b,c&from=vibe&pick=<архетип>` с датами
- **THEN** заголовок «Подборка по вашему вайбу: <архетип>», в выдаче отели a, b, c

#### Scenario: Фильтр в подборке
- **WHEN** в подборке включён фильтр «Бесплатная отмена»
- **THEN** остаются только отели подборки с бесплатной отменой

#### Scenario: Неизвестный источник
- **WHEN** `pick` не из известного списка
- **THEN** заголовок «Подобранные отели»
