## Why
Решения пользователя 2026-10-24 (ответы 5а–8а): в итогах «Это твой вайб», «Звёзды подскажут» и «Нарисуй свой отдых» не выводить подборку отелей в окне — вместо неё кнопка «Посмотреть подборку», которая открывает страницу поиска с подобранными отелями.

## What Changes
- **Подборка на `/search`.** Новый режим адреса: `/search?hotels=<id>,<id>,…&from=<vibe|stars|draw>&pick=<id>` плюс даты и гости как сейчас. `from` и `pick` — идентификаторы из известных списков (архетип вайба, знак зодиака, настроение рисунка), не произвольный текст. Отели загружаются по id (как `GET /api/hotels?ids=`), неизвестные и скрытые id пропускаются.
- **Заголовок подборки** по источнику: «Подборка по вашему вайбу: <архетип>», «Подборка звёзд для <знак>», «Подборка по вашему рисунку: <настроение>». Если `pick` неизвестен — «Подобранные отели».
- **Фильтры, сортировка, карта, страницы** работают как в обычной выдаче, но только по отелям подборки; «Изменить поиск» уходит в обычный поиск.
- **Вайб:** в итоге окна вместо 6 карточек отелей — кнопка «Посмотреть подборку» на `/search` с этими отелями и стартовыми датами. Картинка для друзей и «Пройти заново» остаются.
- **Звёзды:** в итоге нет карточки отеля «Звёзды выбрали отель»; кнопка «Посмотреть подборку» с отелями звёзд и датами гадания. Видео — без отеля: знак, прогноз, город (ответ 6б). Статус `role="status"` называет город.
- **Нарисуй:** на шаге 2 нет списка отелей (прогресс «Подбираем отель» остаётся); на шаге 3 вместо отелей и «Посмотреть отель» — кнопка «Посмотреть подборку».
- Подбор отелей (поиск по смыслу, расчёт по осям, звёзды) не меняется.
