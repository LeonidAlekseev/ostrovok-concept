# Design

## Мигание

Причина не подтверждена, исполнитель воспроизводит и находит её до исправления. Гипотезы:
- `lg:h-[calc(100dvh-2rem)]` и `h-[70dvh]`: на телефоне при прокрутке панель адреса меняет `dvh`, `ResizeObserver` вызывает `instance.resize()`, WebGL-холст очищается и перерисовывается кадром позже. Возможное исправление — `svh`/`lvh` или пропуск resize без изменения размера.
- наведение на карточки под неподвижным курсором при прокрутке меняет `activeId` и перерисовывает маркеры-порталы.
- `fitBounds` при пересоздании `hotels`.

## Атрибуция

Правила OSMF (osmfoundation.org/wiki/Attribution) разрешают сворачивать атрибуцию интерактивной карты только после показа: по нажатию «x», при взаимодействии с картой или через 5 секунд; после сворачивания она должна оставаться доступной (кнопка «i»). Полностью свёрнутая с самого начала атрибуция правилам не соответствует.

Решение пользователя (1а): `attributionControl: { compact: true }`, текст сворачивается через 5 секунд после загрузки или при первом взаимодействии с картой — что раньше.

## Всплывающая карточка

- `Popup` MapLibre, `closeButton: false`, `offset` над маркером; открывается по `mouseenter`/`focus` маркера, закрывается по `mouseleave`/`blur`. Содержимое — React-портал в элемент попапа, как у маркеров.
- На сенсорных экранах наведения нет: нажатие сразу открывает окно отеля (решение 4а).
- Нажатие на маркер не прокручивает список (решение 3а); подсветка карточки при наведении на маркер остаётся.
- Esc закрывает попап; у маркера `aria-describedby` на попап.

## Окно отеля

- Решение пользователя (2а): окно только с карты. Ссылки карточек списка и подборок ведут на страницу отеля, как сейчас. Перехват маршрута `@modal/(.)hotels/[hotelId]` не используется: он перехватил бы все переходы на отель по сайту.
- Параметр `hotel=<id>` в адресе `/search` (через `router.push` с `scroll: false`): «Назад» закрывает окно, обновление страницы открывает его снова; неизвестный id игнорируется.
- Содержимое — `HotelPage` с `stay` из запроса поиска; выбор номера ведёт на `/hotels/<id>/rooms` как со страницы отеля.
- `@/components/ui/dialog`, широкий вариант (`max-w-4xl`, прокрутка внутри), на телефоне — на весь экран.

## Цена без подписей (решение пользователя 6)

Подписи «за ночь» и «за M ночей» убираются: маркер, `aria-label` маркера, всплывающая карточка и `ResultTile`. Чтобы числа на маркере и в карточке не расходились без подписи, маркер и всплывающая карточка показывают ту же цену, что карточка списка: `offerTotal` минимального тарифа за ночи и номера запроса. Сводка над списком («1 ночь · 2 гостя») остаётся. Фильтр «Цена за ночь, ₽» не меняется.

## Сетка списка (решение 7а)

`grid gap-3 xl:grid-cols-2` вместо `sm:grid-cols-2`.
