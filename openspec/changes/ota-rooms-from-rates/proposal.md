## Why
`ota-real-hotel-data` (#214) показал как номера все `static_vm.room_groups`. Разбор данных 2026-10-24 (только чтение `ota_hotels`): `room_groups` — справочник названий номеров от всех поставщиков Островка, а не номера отеля. У Hotel El Globo 182 записи, 99 `room_group_id`, 17 базовых классов (первые 4 цифры `rg_hash`), названия повторяются с вариантами вида и кроватей. Настоящие номера с ценой есть только в `rates` (в выгрузке по Валенсии — 1 тариф на отель). Пересборка `db:rebuild:ota` ещё не запускалась, база не изменена. Решение пользователя 2026-10-24 (1а): номера — только из тарифов, `room_groups` — подсказка Эвалу о виде.

## What Changes
- Номера `ota-*` на странице отеля и в каталоге — только из тарифов выдачи (как до #214); пометка «Нет цены на выбранные даты» и `capacity: 0` для номеров без тарифа убираются вместе с такими номерами.
- `room_groups` используются только для свойств вида (`hotel_room_views`, `scripts/hotel-features.ts`), сгруппированные по `room_group_id`, с пометкой «по описанию»; Эвал говорит «в описаниях номеров отеля есть вид на море», не обещая конкретный номер в продаже.
- Удаление сгенерированных отзывов, оценок по разделам и фото гостей у `ota-*` из #214 остаётся.
- `db:rebuild:ota` остаётся (пересборка `hotels` из `ota_hotels`), теперь с номерами из тарифов.
- Запись в боевую базу (`db:rebuild:ota`, `db:features`, `db:embed`) выполняет пользователь; исполнитель готовит команды и `--dry-run`.

## Impact
- `src/lib/ota/hotel.ts`, `src/lib/catalog.ts`, `src/lib/rates.ts`, `src/components/HotelPage/RoomList.tsx`, `src/components/RatesPage/RoomRates.tsx`, `scripts/hotel-features.ts`, тексты Эвала о виде, тесты. Spec `hotel-catalog` (требование «Только данные Островка у настоящих отелей»).
- Change `ota-real-hotel-data` архивируется вместе с этим после записи в базу.
