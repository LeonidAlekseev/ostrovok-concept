# Proposal

## Why

Решения пользователя 2026-10-21: 47а — шапка на `/search` с 1920 px расширяется вместе со страницей (#87), чтобы края совпадали; 48 — на 320 px иконка меню шапки уходит за правый край, поправить.

## What Changes

- На `/search` с `3xl` содержимое шапки ограничено `--page-max-wide`, как страница поиска; на остальных страницах — `--page-max`.
- На узких экранах (до ~360 px) отступы и промежутки между иконками шапки уменьшаются так, чтобы все иконки помещались в экран на 320 px.
