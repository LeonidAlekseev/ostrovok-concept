# Design

- **Приоритет архетипа.** У каждого архетипа в таблице `vibe.ts` — главная ось. При равном числе совпавших полюсов побеждает архетип, чья главная ось выражена сильнее (|значение| = 1 сильнее 0); при полном равенстве — порядок таблицы. Пример из находки: «Море», «Спа», «Завтрак» слева → «Морской гедонист» (главная ось «Море / Город»). Тест на этот случай.
- **Границы расстояния.** Минимум и максимум `distanceKm` по всем отелям каталога, вычисляются один раз в модуле.
- **`radiogroup`.** Клавиши-стрелки переключают вариант без перехода к следующей паре; выбор (Enter/Space или клик) переводит к следующей паре, как сейчас. Имя группы — «Что ближе: <левая> или <правая>».
- **Ленивые подборки.** Функция или мемоизированный геттер; поведение и порядок подборок не меняются, тесты подборок проходят без изменений.
