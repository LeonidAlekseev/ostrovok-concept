# Design

## Context

Последний этап перевода CSS на Tailwind. Метод и метрики — как в `reduce-page-css` и `reduce-search-css`.

## Goals / Non-Goals

**Goals:**
- `@theme` без `static`; в сборке нет неиспользуемых токенов темы.
- Политика `translate`/`scale`/`shadow` соблюдена во всех компонентах.
- gzip CSS сборки растёт не больше чем на 2 %.

**Non-Goals:**
- Логика и рендер глобуса (Canvas 2D, `public/data/globe.json`).
- Изменение значений токенов дизайн-системы.
- Примитивы shadcn в `src/components/ui/*`: их код генерирует CLI, политика к ним не применяется.

## Decisions

**Метрика** — суммарный размер `.next/static/chunks/*.css` после `npm run build`, сырой и gzip −9 склеенного файла.

**Скриншоты:** методика `reduce-page-css`, viewport 1280×900 и 390×844. Глобус в двух режимах: скрыт (для попиксельного сравнения страницы) и показан на остановленном кадре (для эффектов вокруг глобуса). Состояния: hero целиком, панель статистики, все компоненты, приводимые к политике (карточка в обычном, hover и выбранном состоянии, баннер, шапка). Скриншоты кладутся вне репозитория, в `/tmp/reduce-globe-css-screenshots/{before,after,diff}`, и не коммитятся. В proposal.md записываются только методика и результат pixelmatch по кадрам.

**Проверка `static`:** после удаления найти в сборке токены, которые используются только из модулей через `var()`, и убедиться, что они определены.

## Risks / Trade-offs

- [Токены, нужные модулям, выпадут из сборки без `static`] → Проверка из Decisions и скриншоты.
- [Эффекты глобуса анимированы и плохо сравниваются попиксельно] → Остановленный кадр, `prefers-reduced-motion: reduce`.
- [Рост gzip выше 2 %] → Остановиться и эскалировать с замерами.
