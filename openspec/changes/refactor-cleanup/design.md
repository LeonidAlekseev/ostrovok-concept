## Context

Рефакторинг без изменения поведения плюс одно ускорение. Анализ — по графу codebase-memory (поиск символов без входящих связей, пары `SIMILAR_TO`/`SEMANTICALLY_RELATED`, модули без импортов) с проверкой grep там, где граф не видит связей (динамические `import()`, скрипты, SQL).

## Decisions

### Помощники слоя данных
`src/lib/db/anon.ts` (server-only) собирает то, что повторялось: анонимный клиент без сессии, `isRealHotelId` (`ota-<1…15 цифр>` при настроенном Supabase), `warnShort` (вид ошибки и до 200 символов сообщения, без ключей), `readOrNull(hotel, what, read)` — «не настоящий отель или ошибка → `null`», `catalogCached(name, read)` — `unstable_cache` с тегом и сроком каталога. `unstable_cache` остаётся: проект не включает Cache Components, и гайд Next 16 «Caching without Cache Components» его поддерживает.

### Маршруты
`src/lib/api.ts`: `CDN_CACHE_HEADERS` (5 мин CDN, час stale), `apiError(status, message)` → `{ error }`, `loadVisibleHotel(id)`. Тексты ошибок — короткие английские: их читают логи и разработчик, клиент смотрит только на статус.

### Готовые карты шума
Альтернативы: (а) ускорить SQL — пересечения полигонов EEA по кругу 300 м и есть основная стоимость, индекс уже используется; (б) материализовать куски по отелям. Выбрано (б): данные шума меняются только перезагрузкой `load-valencia-geo.py`, после которой и так запускается `npm run db:features`.

- Таблица `hotel_noise_maps(lat, lon, radius_m, contours, quiet, day, computed_at)`, ключ — точка и радиус, а не id отеля: функции принимают точку, а два отеля в одном здании делят карту. RLS включена, политик нет, прав у anon/authenticated нет — только через функции.
- `hotel_noise_map(lat, lon, radius_m)` (anon): готовая карта `{contours, quiet, day}` или `null`. Радиус приводится к 1–500, как у исходных функций.
- `hotel_noise_map_refresh(lat, lon, radius_m)` (service role): считает три функции и сохраняет; `contours` — только ночные полосы от 40 дБ (то, что берёт карта), а не здания и Lden.
- `hotel_noise_maps_prune(radius_m)` (service role): удаляет карты точек, где больше нет настоящего отеля.
- Приложение: `hotel_noise_map`; при `null` — три живых вызова, как раньше. Ключ кэша Next меняется, чтобы не смешать форматы.

## Risks

- Устаревшая карта после перезагрузки шума без `db:features` — README и вывод скрипта напоминают; итог страницы (полосы в точке отеля) берётся из `hotel_geo` вживую и не зависит от карты.
- Изменение координат отеля — промах по ключу, карта считается вживую (медленнее, но верно).
