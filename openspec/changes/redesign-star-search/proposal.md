# Proposal

## Why

Пользователь прислал 2026-10-20 макет блока «Поиск по звёздам» и два исходных изображения: небо с Луной (фон) и шар. Ответы: 18а, 19а, 20б, 21а.

## What Changes

- Блок `#stars` по центру: сверху шар с зодиакальным кругом (12 знаков) и орбитой с двумя планетами, золотой заголовок, текст с лавандовыми выделениями «Луна в день заезда» и «подскажут город и отель», кнопка-пилюля «Найти по звёздам» с градиентом синий → фиолетовый, золотой обводкой и иконкой искр. Фон — изображение неба пользователя.
- Круг и орбита — тонкие золотые линии поверх изображения, круг медленно вращается; при reduced motion неподвижен (18а).
- Изображение шара пользователя заменяет нарисованный шар везде: блок, анимация гадания, результат, видео (19а).
- Заголовок — текущий шрифт с золотым градиентом, без нового шрифта (20б).
- Запуск сразу после `polish-prices-and-cancellation`, раньше страницы отеля (21а).
