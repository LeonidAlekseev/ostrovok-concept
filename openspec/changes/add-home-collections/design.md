# Design

## Decisions

**Отбор:** детерминированный — из каталога по условию подборки, сортировка по рейтингу, затем по цене; по одному отелю на направление, первые 4. Карточка — тот же компонент, что в результатах поиска, если он подходит по виду, иначе компактный вариант.

**Даты в ссылке:** стартовые даты формы (завтра и послезавтра) и 2 взрослых, 1 номер; до гидрации ссылка без дат.

**Раскладка:** на desktop — 4 карточки в ряд, на мобильных — горизонтальная прокрутка с snap.
