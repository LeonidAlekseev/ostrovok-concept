## ADDED Requirements

### Requirement: Пины только видимых отелей
Пины и карточки отелей на глобусе SHALL строиться только из отелей, видимых в текущем окружении: в production — только города с настоящими отелями.

#### Scenario: Глобус в production
- **WHEN** главная открыта в production
- **THEN** на глобусе пин только у Валенсии, и карточки у пина — её настоящие отели

#### Scenario: Глобус в preview
- **WHEN** главная открыта в preview
- **THEN** на глобусе пины всех городов с отелями
