# Proposal

## Why

Шаблоны «Оформление бронирования — гости, контакты, оплата» и «Подтверждение бронирования — статус, детали заказа» (запрос пользователя 2026-10-19, кликабельный прототип). Оплата — только форма, без платёжного провайдера.

## What Changes

- Страница `/booking` по параметрам предложения: сводка заказа и форма — гости по номерам, контакты, пожелания, оплата, согласие с условиями.
- Оплата: для тарифов «Оплата сейчас» — форма карты с проверкой (номер по Luhn, срок не истёк, CVC); для «Оплата в отеле» — без карты. Демо-пометка: деньги не списываются, данные никуда не отправляются.
- Отправка создаёт бронирование в хранилище браузера (номер `OS-XXXXXX`, статус «Подтверждено») и ведёт на `/booking/confirmation?id=<номер>`.
- Подтверждение: статус, номер, детали заказа, условия отмены, ссылки «Мои поездки» и «На главную».
- Если пользователь вошёл (демо-сессия), контакты заполняются из сессии; бронирование без входа разрешено.

## Capabilities

### New Capabilities

- `booking-checkout`: оформление бронирования.
- `booking-confirmation`: подтверждение бронирования.

### Modified Capabilities

Нет.

## Impact

- Новые `src/app/booking/*`, `src/components/Booking*/*` (имена — на усмотрение исполнителя).
- Использует контракт предложения и хранилища из `add-prototype-foundation`.
- Зависит от `add-prototype-foundation`. Не пересекается по файлам с другими changes плана.
