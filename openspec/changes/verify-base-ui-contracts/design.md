# Design

## Context

Виджеты на Base UI: combobox направления, popover дат и гостей, вкладки режимов, шапка. Контракты описаны в `openspec/specs/manual-search`, `search-modes`, `site-header`. См. proposal.md — Why.

## Goals / Non-Goals

**Goals:**
- Каждый контракт из перечисленных сценариев подтверждён тестом или явно отмечен как не проверяемый автоматически.

**Non-Goals:**
- Визуальная проверка (это `migrate-composite-components`, задача 4.1).
- E2E-тесты в браузере.

## Decisions

**Component-тесты на Vitest с jsdom и Testing Library.** Они запускаются в том же `npm test`, что и юнит-тесты. Альтернатива — Playwright E2E — отвергнута на этом этапе: требует браузера и медленнее; её можно добавить позже для визуальной проверки.

**Тест Escape проверяет остановку распространения.** Родительский обработчик `keydown` не должен получать событие, если список открыт.

## Risks / Trade-offs

- [Base UI в jsdom ведёт себя иначе, чем в браузере] → Для позиционирования и фокуса проверка ручная; в тестах проверяется логика закрытия и состояние.

Откат — удалить тесты. Исправления в компонентах откатываются коммитами.
