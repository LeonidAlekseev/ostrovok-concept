## Why

Живой прогон 2026-10-25 (#252): `meta/llama-3.2-11b-vision-instruct` игнорирует схему JSON и отвечает прозой — 0 годных ответов из 7, только тратит окно ответа. Пользователь решил убрать её из цепочки (вопрос 21б, 2026-10-26).

## What Changes

- Цепочка фото: `nemotron-3.5-super-vl` → `minimax-m3.1-flash`. Освободившееся время окна достаётся этим двум моделям и текстовой цепочке; общие сроки ответа не меняются.
- Особый случай без `reasoning_effort` для llama удаляется, если больше нигде не нужен.

## Impact

- Спецификация `assistant-search`, требование «Сбой модели фото».
- Код: `src/lib/ai/model.ts`, `src/lib/ai/model.test.ts`, README (раздел моделей, если есть упоминание).
